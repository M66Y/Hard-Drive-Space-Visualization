# AsukaLens 项目记忆

用于恢复开发上下文及维护精简的项目知识，不替代项目规则或事实证据。项目根目录是本 Skill 所在目录向上三级；正文中的项目路径均相对该根目录。

## 接续工作

先看 references/checkpoint.md，再按本次范围读取 references/decisions.md 和其链接。用 `git status --short --branch`、当前提交、相关代码及迭代验证新鲜度；明确已提交、工作区半成品、测试原型、旧预览和正式发行版。事实冲突以核实后的代码/证据为准，纠正记忆，不把计划写成已实现。

长期规则仅维护在根 AGENTS.md；现状与计划分别由 docs/project-status.md、docs/development-plan.md 维护。记忆是索引和交接摘要，不复制整个规则、历史或原始日志。新需求不能仅因出现在记忆中就视为实施授权。

## 更新触发

- 环境可靠提供上下文使用量时，以 **70%** 为检查点：在当前不可中断操作完成后的最近安全边界更新。仍处同一窗口且没有新增事实时不重复写；后续到 **85%** 或收到即将压缩/交接通知时，有新事实则再检查点。
- 无法读到可靠百分比时，不估造 token 数或声称已跨过百分比；改为**每 20 次工具调用或连续工作 30 分钟（先到者）**检查一次，并在主要阶段结束、重大用户决定、暂停/交接前及上下文恢复后检查。合并同一安全边界的触发，避免重复写盘。
- 这是智能体执行规则，不是后台监测器，不修改平台自动压缩设置，也不能保证收到压缩前通知。关键决定和验证结果及时落盘，不能全押在阈值触发。

## 每次保留什么

checkpoint.md 只保留日期、已核对基线、当前目标/进度、未提交文件归属、验证范围、明确未完成项、下一步和本次授权的时效。decisions.md 记录会影响后续取舍的决定：日期、选择、原因、被放弃或延期的方向、边界及证据链接。过时事实标明已被哪一记录替代，长历史回链 iterations/ 与 Git，不无限追加流水账。

每次先同步受影响的正式现状/计划，再压缩更新记忆；SKILL.md 只有工作方式改变时才修改。单个 checkpoint 以约 120 行为上限，超过时删去重复并回链证据，不删除唯一决策理由。无新事实无需制造仅改时间戳的提交。更新完成核对链接、状态与隐私，随对应迭代归档提交，不顺带提交别人的修改。

不记录个人路径/文件名、邮箱、凭据、原始诊断、用户图片、设备标识或原始 NTFS 记录。只保留公开项目标识、受控类别、脱敏计数与仓库相对路径。一次性 VHD、提权、打包或发布许可不得变成长期授权。
