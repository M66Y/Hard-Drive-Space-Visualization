```powershell
dotnet tests/bin/Release/net10.0-windows/DiskAtlas.Tests.dll --ntfs-personal-timing-tests
```

真实计时入口为 `tests/bin/Release/net10.0-windows/DiskAtlas.Tests.exe --ntfs-personal-timing`，只能在当轮来源与预算明确获准后使用。stdin 依次输入两行：第一行为选定顺序 `FO`、`OF` 或 `FOOF`，第二行为当轮已授权目录的绝对路径；不提供默认真实盘目录。v2 F 包含 Coordinator 发布核验，不附加逐对象审计；每次扫描取消上限为 10 分钟，通信总期限为 12 分钟（不是额外等待 12 分钟），不把 GUI 绘制计入该口径，私有紧凑元信息比较位于计时外。本轮已结束，不因保留入口继续扫描。
