# 第 2 轮：扫描进度与图表交互

日期：2026-11-02。基线提交：`4814d20e4b96e5de8de4f9892245404734716b09`。

## 范围与确认

用户要求第 2 轮迭代，并批准“扫描进度与图表交互”方案：透明轨道、深色已处理段、移动透镜图标、右侧估算百分比；图块轻微回弹和关闭动效入口。普通开发迭代，不升级正式版本、不打包、不创建标签或 Release。

七项保留功能继续存在。本轮不改扫描策略、缓存可靠性规则、占用计算、硬链接处理、文件操作权限或背景设置流程。

## 决策与关键文件

- `Core.cs`：`ScanProgress` 增加可选的已处理/已发现目录任务计数及估算属性；包含根任务，新任务调度前先累计分母，完成后累计分子，使用原子计数。先读取完成数再读取发现数，避免并发采样得到分子大于分母。旧调用仍可省略新参数。
- `MetadataVerifier.cs`：核验以旧快照目录数为分母，完成任务累加；目录内部每 256 项也可发布当前文件计数，延续 100 ms 限频，不增加核验之外的磁盘读取。
- `ScanProgressControl.cs`：未知总量与估算分开，未知总量用往返短段指示，不按时间增长百分比。读取和复用使用同一任务计数，核验另行计数，整理沿用读取计数，运行中最多 99%。完整结果由界面确认后才显示 100%；跳过/占用未知等不完整结果、取消和失败各有终态。终态拒绝迟到进度，辅助读取使用包含真实状态的只读文字，避免通用 ProgressBar 暴露错误的可编辑数值 0。
- `MainForm.cs`：接入进度、完成/不完整/取消/失败状态；保留原有扫描身份与取消隔离。底部行从 4 增至 48 个设计像素；空间分布标题右侧增加“减弱动效”。初始值依据启动时系统窗口动画偏好，仅本次运行有效，不新增持久配置。
- `TreemapControl.cs`：内层高光轮廓回弹，外部面积、嵌套布局、文字与命中矩形不变。最多一个图块，目标时长 360 ms、40 ms 定时器间隔，只失效对应矩形并跳过裁剪区外图块。帧绘制使用已缓存布局，不遍历整棵文件树；布局改变、隐藏、禁用或减弱动效时停止，销毁时释放定时器。
- 测试项目显式链接新控件，补充估算边界、真实计数、取消整理、阶段切换、迟到回调、动效开关与面积/命中不变的检查；界面测试将未处理异常直接输出，避免静默弹窗后超时。
- `README.md`、`使用说明.txt` 同步行为和限制；`AGENTS.md` 仅更新实现事实。

## 健壮性与限制

百分比只是当前阶段目录任务估算，不是文件数量、大小、全流程完成度或剩余时间。新目录出现可能下降，阶段变化可能重置；大单目录可能较长时间停在较低估算。缓存整子树只算一个复用任务，核验结束仍需读取/复用及统计整理。没有预先重复走访磁盘来凑精确分母。

原有错误、未知占用、取消隔离和可靠性降级保持；结果不完整时不显示成功 100%。计数与图表动画不决定最终统计和命中。关闭动效仍显示静态高亮、真实计数与未知总量提示。

未验证其他 DPI/跨屏缩放、长时间整盘扫描中的中间百分比人工观感、实际物理 I/O 或其他前台应用响应；不据此宣称扫描提速或所有设备均已验证。完整日志系统、自定义背景、高速单目录并行与增量追踪升级仍不属于本轮。
