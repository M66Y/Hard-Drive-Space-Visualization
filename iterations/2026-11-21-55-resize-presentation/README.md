# C55：缩放重复合成与中间擦背景

2026-11-21，用户要求继续修复连续缩放的瞬间闪黑和卡顿，保持现有布局、背景和动效，先打开正常功能DIB候选、不设默认。

**当前结果：卡顿的两处明确热点已优化，必要检查通过并已展示C55；瞬间闪黑尚未判定修复，等待用户体验。** 最终早期离散GDI取点仍有黑色，不能以返回后的0黑或耗时下降关闭缺陷。

## 定位和定点修改

固定序列中重复背景调用约880次，SplitPanel中间擦背景累计约1.14秒。精确根缓存因GDI+位移不能原生复制时，原来会再次绘制壁纸和浅色遮罩。现在将同一已合成的不透明根缓存通过GDI+发布，限整数平移、原比例和受支持单位；原生复制守卫不变，非整数/缩放/旋转保持旧回退。两档零差异测试覆盖平移、带孔裁切和旧边界。

第二处只作用于DIB候选的逻辑尺寸事务：中间SplitPanel擦背景暂不合成，等原有布局事务稳定后自然完整补画。最终单次固定序列省略155次中间擦背景；没有停用WM_PAINT、改变窗口可见性或隐藏图表动效。新测试自然变更尺寸后取可见父面板像素，核最终补画、重绘所有权和资源释放，不先强刷掩盖残留。

尝试过`SWP_NOREDRAW`后明确撤销：黑点从NcEntering移动到PositionEntering，未消除。失败结果保留在[对照记录](rejected-experiment.json)，最终生产源码不包含该尝试。未新增缓存内存，不扩展128MiB预算。主窗布局和RenderSession代码保持前像不变。
