# NTFS 快速扫描可行性研究

日期：2026-11-12；基线：`1d098b4`。用户希望接近 WizTree 的整卷扫描速度，先研究可选 NTFS 快速扫描路径。

核对 `Core.cs`、`ScanPolicy.cs`、`NativeStorage.cs` 和 `ChangeJournal.cs`，以及 Microsoft Learn 的 USN 枚举、文件记录读取、MFT 与属性结构说明。研究结论、来源链接、当前实现边界、权限与统计契约、原型分阶段验收见 `docs/ntfs-fast-scan-plan.md`。不能把 USN 名称枚举当作已获得文件大小和分配空间，也不能从 MFT 能力推导实际加速倍数。

建议独立只读原型先校验记录与特殊文件，再测读取、建树、汇总和补查的总成本，收益明确后再确认权限助手和产品集成。两种大小口径、硬链接、取消和错误恢复是必须保留的契约。

本轮仅修改文档；没有请求 UAC、扫描磁盘、修改系统日志设置、编译、打包或发布。核对文档链接、术语和实现/提案区分；公开文件已检查本机路径和凭据标记。无测试夹具或原始磁盘数据。补丁与 SHA-256 同目录保存；检查其反向适用性以验证可恢复性。
