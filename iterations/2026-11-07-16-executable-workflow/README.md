# 直接发行 EXE：本机完整使用流程验收

日期：2026-11-07。基线：`f4bf448c859a4b5ce3ef82c0e2bb20070af5ebd0`。用户明确要求先补齐本机发行 EXE 的使用流程；沿用已批准的自包含便携包、独立测试安装身份及本机临时包方案。本轮没有正式发布、创建标签或上传二进制，也不恢复 PERF-001 的性能追测。

## 改动与健壮性审查

过去的包级功能检查由测试宿主加载包内生产 DLL，不能替代真实 `AsukaLens.exe` 入口。本轮给 `Program.Main` 接入显式 `ASUKALENS_DATA_DIR`，复用现有主窗背景路径和诊断根目录参数；未设置时默认 AppData 和配置格式不变。指定目录时标题附加“隔离数据”，不改变扫描功能。

`src/AppDataLocation.cs` 只接受存在的绝对目录，拒绝空白、相对路径、卷根目录、不存在目录和文件。解析失败发生在诊断服务及背景加载之前，不回退个人设置；异常提示仍使用已有白名单。该变量只重定向软件持久数据，不是操作系统沙箱；验收启动器只对本次进程设置变量，并核对夹具归属。没有新增命令执行入口、遥测、日志字段、服务或管理员权限需求。

关键文件为 `Program.cs`、`src/AppDataLocation.cs`、测试入口和 `tests/AppDataLocationTests.cs`；启动方法、验证边界和状态同步到 AGENTS 与 docs。主窗按 `using` 释放，已有进程生命周期互斥体继续覆盖主窗与诊断退出阶段。运行中的真实 EXE 已实际验证安装/卸载阻止行为，没有结束用户进程。

## 实际 EXE 流程

使用 computer-use 操作本轮便携 ZIP 中的真实 apphost，随后操作相同载荷安装后的 apphost；没有复制测试宿主、替换程序集或通过反射模拟这些人工操作。自包含载荷为 Windows x64 / .NET 10.0.14；本机已有 SDK，因此不将运行时路径核验称为无 .NET 环境验证。
