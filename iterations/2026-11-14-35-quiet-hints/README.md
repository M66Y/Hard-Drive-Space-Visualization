# C35：减少解释气泡遮挡

2026-11-14。基线为`9ac1f0b`及其上的C30–C34未提交工作区。用户指出多处悬停解释挡视野，批准统一减少打扰；已确认关闭旧窗口。第一阶段仍未接受，不把本轮实现当作最终收尾或Git冻结。

## 改动

- 磁盘活动不再将整段动态AccessibleDescription注册到整卡tooltip，原每秒样本/时钟仍更新无障碍信息；完整数据保留在现有详情，按钮仅简短静态说明。
- MainForm、进度、树图和监测提示统一使用AppToolTips：延迟/再次显示均1000ms，最多5000ms，内容框限360×220 DIP及工作区，按字素换行，超长/超高明确省略。可见文本最多600 UTF-16单位，原始注册值不被截改。
- 进度提示固定为简短估算说明，动态阶段/路径保留在完整可访问描述和扫描详情；树图提示保留名称/大小/占比，未知值仍明示，去掉重复路径和操作教程。
- 列表改用一个GridHoverHints计时器：仅名称格和有说明表头，4 DIP移动重新等待，约1秒停稳后显示；显示前再核对位置/行列/原文/真实活动窗体。滚动、查询/行变、键鼠、隐藏、失焦、句柄销毁或释放均取消。数字格不再重复弹完整路径。保持原生数据/UIA、选择、排序、B双行和C32绘制事务。
- 提供器和字体随所有者释放；测试预览的格提示在主窗回调后转换公开根别名，并在READY前拒绝未转换的夹具根路径。不记录或上传提示文本。

范围与理由见[方案](../../docs/ui-quiet-hints-plan.md)。背景、1.15倍柔光、扫描/统计与黑块延期决定均不变。
