## 改动

- `WallpaperTable.OnSizeChanged` 的外层布局持有覆盖 `base`、自身圆角 Region 与子内容裁切更新，避免布局内部先呈现、随后才更新最终裁切。
- 新增 `ResizePixelPolicy.Prepare(Control, ref Message)`：仅在 `WM_WINDOWPOSCHANGING` 的有效几何变化中添加 `SWP_NOCOPYBITS`，不改变其余标志、消息或位置尺寸字段；尊重 `NOMOVE`/`NOSIZE`，空指针、其他消息、无有效变化及最小化窗口跳过。顶层 Form 纯移动也跳过。
- 接入 MainForm、WallpaperTable、WallpaperGrid 与壁纸分隔面板的原生位置消息。目的为避免复用按旧窗口坐标绘制的像素，不改变布局、背景透出、圆角、1.15 倍沿边柔光、无说明框与无悬停提示。

本轮实现与测试范围为 `MainForm.cs`、`Wallpaper.cs`、`src/UI/ResizePixelPolicy.cs`、`tests/ResizePixelPolicyTests.cs`、`tests/Program.cs`；本记录另行归档。不覆盖、重置或顺带提交继承 WIP。
