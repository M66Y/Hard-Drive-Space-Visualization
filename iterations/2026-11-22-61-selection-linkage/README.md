# C61：第二阶段图表、列表和详情联动

2026-11-22。源码基线 `93b80abcd32272cb7ba860c4a48aaf00dd657374`（C60方案，开始时干净main/origin）。用户已批准实施；本轮交付真实可运行开发版，阶段整体接受等待用户体验反馈。没有打包、标签或Release。

## 解决的问题

把“找到大块占用→准确选中对象→列表定位→核对详情→进入或定位文件”接通。原图块内部文件仅被绘制、点击仍落到父块；查询重建MapItem、同名/共享身份及连续查询也可能丢失或串联选择。现在用当前结果树对象引用区分入口，并以来源/查询/选择代际约束异步发布。

保留整体布局、可见背景/焦点、C57默认/C55回退及原1.15倍沿边柔光。没有改变扫描/大小/权限合同，没有悬停文字、自动说明框、新持久化或用户文件写入。

## 可体验的变化

- 图块与列表双向选择，就近滚动、跨页定位；现有页脚短反馈和一次700ms轻浅行提亮，不抢焦点、不反复顶行。减弱动效、隐藏/最小化/关闭会停计时器。
- 内部文件可真实命中并沿边柔光；单击保持总览，列表只标父目录“所在目录”。主动“在列表中查看”才进入父目录、选中该文件。旧聚合没有成员映射时不猜测。
- 固定底部摘要为长名称及两种大小分别留位，按对象显示进入目录/定位文件/类型明细/当前列表。完整路径、修改时间、未知与共享信息在主动详情窗口查看，路径可复制。
- 排序/口径/搜索连续切换只发布最新查询，保留仍有效的选择；失效/过滤/新结果树解除旧对象，不清空用户搜索来强行定位。快照定位继续核对路径身份，异步核对过期不得打开旧文件位置。

实现入口为MainForm、TreemapControl、WallpaperGrid及src/UI三个小类。参见[联动说明](../../docs/selection-linkage.md)和[方案](../../docs/ui-stage-two-linkage-plan.md)。
