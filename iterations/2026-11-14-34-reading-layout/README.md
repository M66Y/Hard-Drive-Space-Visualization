## 用户确认与结果

用户否定首版窄高交互预览，认可第二次1440×940静态图的背景比例，选择B名称＋路径双行，并确认统计卡略矮、更早合并细碎图块三项同步原生实施。完成后先看真实效果，再决定第一阶段是否收尾。范围见[方案](../../docs/ui-readability-preview-plan.md)。

- 大文件名称单元格分为文件名和相对父目录两行，58 DIP行高；普通目录/类型保持44 DIP。大小和占比右对齐，独立位置列隐藏；位置排序保留在名称表头右键菜单，启用后表头明示排序状态。
- 路径使用单行路径省略，完整路径仍可悬停核对。原MapItem名称、Entry身份、查询和选择不改；本机可访问值包含两行。正文和次行分别裁切，不越过单元格及脏区，次行字体由窗口持有并释放。
- 大文件数字列按至多500个结果的不同显示字符串及表头一次测宽，含未知/共享说明；把原先多余的固定预留还给名称区，不在绘制回调测量，不缩普通字号。
- 统计卡所在行88→80 DIP，卡片实际约80→72 DIP；主工作区多8 DIP，原说明不恢复，背景cover和焦点不改。
- 主图从原始有界MapItems按52×36 DIP可辨阈值聚合；不改变字节权重，准确合计Count/UnknownFiles，缩放重新使用原集合。原有上游聚合按实际数量合并，不按1项处理。新合并成员的原始选择映到显示聚合的同一轮廓，选中与悬停不重复叠光。

列表保留全部查询结果。既有240项以上的上游聚合不携带逐成员身份，不能凭名称或大小猜测未提供对象的归属；本轮不宣称补齐这个旧边界，也不调整Top500查询合同。1.15倍沿边柔光、固定列表底图/局部滚动呈现与原生输入保留。黑块问题仍按用户要求暂缓。

## 真实窗口观察

使用`--stage-one-preview b --reading-fixture`，真实扫描本轮自建80个普通文件、约20.159MiB，配置隔离、路径显示公开别名。包含同名、同前缀和长相对路径，未扫描个人目录、调用VSS/raw或启用实际磁盘监测。

- 144 DPI最小窗口：客户区1658×1114，模板/实际行高均87像素。实看次行、选择第二个同名文件后核对独立路径及3.5MB；Ctrl+End选小文件后聚合轮廓可见，滚轮向上后背景位置保持。
- 144 DPI常用窗口：客户区2138×1354，模板/实际行高87像素；普通长度文件名完整可见，次行能区分正式版本与历史备份，80项及真实扫描结果可见。
- 两次最小预览已正常关闭并各确认`CLEANUP ... completed=True`。常用预览留给用户体验，关闭后才清理其在用夹具；未把在用文件当冗余删除。
- 常用画面右上方存在其他应用浮层，未操作该浮层，未将含其内容的截图归档。用户看真实主窗评价，程序位图/断言不代替观感接受。
