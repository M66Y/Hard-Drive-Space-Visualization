## 改动与针对性

新几何观测显示，WM_NCCALCSIZE返回时原生窗口和客户区仍是旧范围；首次WM_NCPAINT进入才出现扩大后的客户区及黑点。普通GDI无法在尚不存在的目的区域铺底。此证据支持背景独立保留的方向，不证明所有黑块同因。

C57使用自有cloaked、不可交互且不进任务栏的源窗口，将现有准确裁切的不透明DIB背景交给DirectComposition；目标明确位于全部原生子控件之后。保留WinForms控件、原布局/字体/背景/1.15倍动效与C55快路，root不加C56 layered样式。没有截图复制、拖动冻结、录屏或系统设置更改，没有个人卷操作。

源初始化延后到主窗首次显示事务返回；以后先按预计几何准备，再以NCCALCSIZE实际输出修正最大化等边框变化。背景应用时直接发布新图像，不依赖根窗口一定收到GDI重绘。代际守卫、重入隔离、失败撤树和自有对象释放均有检查；失败回退C55。应用像素预算仍128MiB，系统/GPU额外存储未测。
