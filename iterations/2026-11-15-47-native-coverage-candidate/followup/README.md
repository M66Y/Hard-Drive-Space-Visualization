# C47复审后的定点取证与静态复用

用户补充：两种模式都可能受影响／未区分，残留重点为闪黑或黑边及卡顿。旧C47候选仍按失败保留；没有录屏、变更系统设置、私人扫描或正常版集成。

## 已补证据

诊断schema v3保留原32点双阶段合同，另设每geometry独立24点早期预算，每阶段4个根客户区点，child占点明确Unknown。无强刷、无窗口绘制参数变化。

12步纯画布候选的早期通道：NcPaintEntering有效44点／黑20；EraseEntering有效44／黑20；EraseReturned有效44／黑0；NcCalcSizeReturned及WindowPosChangedEntering各有效44／黑0。原后期几何44个点仍匹配帧，恰好证明晚取样会漏掉用户所见空档。无日志截断或观察失败；诊断自身约435ms，不称无扰动。

非启动组NcPaintEntering→EraseEntering约6–10ms；EraseEntering→FrameCopied约144–237ms。后者是发布路径区间，包含取DC、绘制复制和少量诊断，不等同于单个API或DWM最终帧时间。新尺寸帧预备完成不代表已及时呈现在屏幕，不能以缓存或FrameCopied计数关闭闪黑。

## 静态复用

原型默认关闭路径保持原输出。候选将静态底图与两条沿边柔光拆开，仅缓存当前精确size/DPI/state/图片/主题，不跨尺寸拉伸；仅一张、最多8M像素，并计入帧＋缓存128MiB总上限。动画只使边带失效；新geometry首次仍完整绘制。

`--resize-scene-cache-tests`两档各51项／16组，144DPI比较40,089,600、96DPI比较17,817,600个RGBA像素，均零差异，worker正常结束。新候选覆盖专项两档各91项／1,075,200RGB像素通过。本次动态真实复审尚未完成，不冒充通过或提速。

当前固定尺寸序列缓存build仍多、命中少，不能拿它证明实际缩放大幅加速；该缓存主要减少相同geometry/state动效的重复文字／卡片／列表绘制。主窗受限Panel路径没有因此迁移为单画布。

## 拒绝的原生复制试验

从GDI+ Bitmap的Graphics.GetHdc借出源DC并SRCCOPY，完整24,576像素不匹配，试验立即撤回。`rejected-frame-copy/`保留两份源码，不在活动编译，所有Form调用和命令入口均移除。没有放宽像素阈值。

新增测试初有SetClip/Region.Equals API编译错误，已修正；一次构建失败后误运行旧DLL，两个未知新参数落入旧核心38项入口。这两次输出不算新专项通过，后续改为构建失败即停止。最终测试构建0警告；新复制试验本身明确失败，不用旧输出追认。
