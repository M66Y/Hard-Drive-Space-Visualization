# C28：同快照正确性对照

2026-11-13，基线 `420a0549dd1225e467956f9e62fe319ce0cc5aad`。真实对照返回 `Matched`：两种扫描读取同一自持 VSS 来源，已包含入口、类型、完整身份、文件逻辑大小、对象分配量与链接数一致；两路独立重算的根大小、去重占用、文件／目录数量均有效，排除集合完整且一致。占用均已知，来源绑定、预算与本次快照清理确认，进程退出码为 0。无需差异补查，没有追加扫描。

## 改动

- 测试 apphost 增加 `--ntfs-same-snapshot-comparison`；目录从 stdin 经同用户、对端 PID、父进程启动时刻及同 EXE 验证的私有管道进入 MTA 助手。只返回固定类别与布尔摘要，响应总量最多 16 KiB。
- 原 `DiskScanner` 新增仅供内部启用的单次遍历预算。入口、名称、目录路径和队列均有界；越界不被吞成部分完成，异常取消并等待后台任务退出。普通产品扫描未启用该预算。
- 比较器按相对入口与完整身份核两种大小、硬链接和根统计。最多 1,024 个不同差异对象可在同来源独立补查元信息。快扫排除声明取实际返回值，不能用普通扫描的跳过项代替。
- 取消后等待清理事实；通信截止不强杀持有来源的助手，退出或异常不冒充快照已清理。父进程 10 分钟上限包含授权等待，可能提前耗尽；不自动重试。

## 结论与限制

本轮关闭“同源快扫与原扫描器统计是否一致”的核查项。已有重解析点按两种扫描共同的跳过策略处理，不等于读取了链接目标或整个未排除命名空间。没有差异，所以真实差异补查分支未触发，其覆盖来自合成测试及代码审查。

本次不是产品端到端性能基准，不回溯断言 C27 的全部差异都由外部变化造成，不外推到所有目录、格式、设备或 Windows 10 新后端。产品默认入口、原计时流程、界面和正式 v1.5.0 未在本轮更改；无打包、标签或 Release。下一项按用户顺序处理主界面可读性。
