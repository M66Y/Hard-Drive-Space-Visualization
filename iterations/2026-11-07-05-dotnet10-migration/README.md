# .NET 10 LTS 系统安装与项目迁移

基线：`2beb1445d4c18da19eaed74dde565e0770dcce51`。用户在审阅迁移方案后明确选择系统安装 .NET 10 SDK。本轮仅迁移运行环境、同步构建/使用入口与兼容检查，保留七项核心功能、背景配置格式及产品版本字段；未启动日志系统或扫描重构。

## 安装与改动

- 使用微软官方发行元数据选择稳定的 Windows x64 SDK 10.0.403，包含 Windows Desktop Runtime 10.0.14。安装包约 205.4 MiB，SHA-512 与官方值一致，Authenticode 状态 Valid，签名证书组织为 Microsoft Corporation。安装参数为 `/install /quiet /norestart`，退出码 0，无需重启；现有 .NET 9 SDK / Runtime 保留。
- 应用与测试项目一起改为 `net10.0-windows`。`global.json` 固定 SDK 10.0.403，`latestPatch` 允许相同 10.0.4xx feature band 的后续补丁，禁止预览 SDK；换 feature band 另行验收。
- `build.ps1` 同步新目标目录，其语法检查通过，本轮未执行 publish 或打包。当前预览为 `bin/Release/net10.0-windows/DiskAtlas.exe`，升级前 `bin/Release/net9.0-windows/` 暂留作回退。
- 测试入口输出实际 .NET / WinForms / 架构。背景独立子进程优先使用父进程的 dotnet 宿主，核对版本一致。新增 `DesktopCompatibility.cs` 覆盖生产目录拖放处理与复制路径菜单。
- README、使用说明、AGENTS、项目现状及迁移方案同步依赖与命令。SDK 安装不等于正式软件发布；旧 `软件/` 和 ZIP 仍是 .NET 9 构建。

官方来源与安装校验摘要见 `validation.json`。首次 PowerShell 下载未开始正文传输，结束本轮该下载后改用有超时的 curl 完成；未绕过哈希或签名检查。

## 健壮性与限制

本轮没有更改扫描、缓存、统计或背景存储逻辑。已核查 .NET 10 GDI+ 异常变化，现有图片/绘制捕获同时处理 OutOfMemoryException 与 ExternalException；无需新增异常消息记录。没有新增网络请求、遥测、用户行为采集或诊断上传。

FileDrop 检查使用合成真实目录及数据对象调用生产事件处理，没有实际测量资源管理器跨进程鼠标拖放手势。剪贴板仅在本轮复制操作后读取合成路径，并在仍是本轮路径时清除；不读取或归档之前的内容。未覆盖其他 Windows / 架构、多显示器切换、系统高对比切换及逐帧冷启动；不宣称扫描加速。

回退基线明确，旧构建及 .NET 9 均保留；后续如需源码回退，使用新提交恢复相关文件，不重写远程历史。背景 v1/v2 格式未变，不需搬迁个人设置。
