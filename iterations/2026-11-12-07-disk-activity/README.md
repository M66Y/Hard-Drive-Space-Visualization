# MON-01：磁盘活动面板首版

日期：2026-11-12。基线：`6f797a30da0edb767f4f8a608402fa8327491c4b`。用户要求按计划连续开发一小时，并在看到实际窗口的合成效果后确认采用进度条上方的布局，继续接入每秒采样、物理磁盘映射、暂停与不可用状态。本轮为普通开发，不打包或发布；v1.5.0 资产保持不变。

## 用户可见行为

初始折叠，不预先采样；展开显示最近 60 秒曲线、活动时间、读写 MiB/s 和平均响应毫秒。默认跟随扫描目录，也可手动选择已验证的物理磁盘，图中显示“磁盘 N”和“整块磁盘，包含其他进程”。同一实体盘上的多个分区使用同一指标。

收起、最小化及退出暂停并释放；恢复与目标变化重新建立基线，不把首样本、缺值或暂停时间伪装成零。4 秒未更新会清空当前指标，曲线继续移动/过期，迟到值不能恢复成新鲜指标；时钟回退丢弃历史。设备与电源通知触发重新核验/预热，真实硬件场景仍见下方限制。

在最小窗口首次检查发现主表格的自动列宽会让面板及其他内容越过右边界，修为明确的百分比单列宽。144/96 DPI 的最小与常用尺寸检查及原 UI 回归通过，未改扫描算法或统计含义。

## 关键实现与健壮性

- `src/Monitoring/DiskActivitySource.cs`：延迟初始化 PDH 英文通配计数器，DOUBLE/NOSCALE/NOCAP100，按同一实例名组合四指标；每项状态/数值独立核验，不借另一磁盘。采集时间在格式化读取前记录，迟到格式化结果仍保留原时间。缓冲上限 1 MiB、4096 项、两次容量尝试，指针只能指向自己的分配区；query 和临时缓冲均释放。
- `DiskActivityResolver.cs`：挂载点 → 卷 GUID → 单 extent → 物理盘描述符，拒绝网络、可移除、多 extent、明确虚拟总线及不明映射。不遍历文件树，不提取型号/序列字符串，界面标签仅磁盘号。
- `DiskActivityMonitor.cs`：一个后台所有者、一格唤醒信号、最新请求替换。快速选择不排队创建原生查询，取消及 UI 回写按版本隔离；关闭不在 UI 等待同步调用，后台最终释放。
- `DiskActivityPanel.cs` 与 `MainForm.cs`：60 点有界内存历史、1 Hz 主窗时钟、过期/断档、键盘按钮/目标选择、DPI/高对比颜色、折叠和窗口状态集成；时钟和字体在退出释放。无采样持久化、遥测、上传或默认提权。

独立只读审查补齐采集时间戳和无先前暂停通知时的恢复重建，未发现本轮范围的阻塞问题。同步原生调用仍不能保证立即取消；进程内旧结果隔离不等于驱动有硬性响应期限。

## 验证与性能边界

应用/测试 Release 构建均 0 警告、0 错误。合成采样/映射/后台编排 174 项通过，含 50 次快速关闭的释放竞态检查；面板 144/96 DPI 各 28 项，主窗集成各 58 项。原有 UI 两种 DPI 回归通过，覆盖扫描预览、取消恢复、结果范围、口径/刷新、长路径、主题和绘制。核心 38、高级 25 项在本小时前一轮通过，本轮未改变扫描器。

中文 Windows 11 上，普通权限真实映射和连续三次 PDH 四指标均有效。实际窗口观察了展开、选盘、曲线更新、折叠暂停及最小化恢复等待。用户协助打开任务管理器同一物理盘页面，近时段低活动约 1% 与本面板趋势相符；高负载和响应时间同步对照尚未完成。未归档任务管理器或桌面原始截图。

`resource-probe.json` 保留四个独立进程 off/on/on/off 的短时观察：1.5 秒预热、5 秒窗口，开启时约 0.93%–0.94% 单核 CPU，生命周期峰值工作集较关闭约高 9 MiB。测量只含后台监测器，无 UI/扫描；CPU 未除以逻辑核心数，峰值含整个子进程初始化，不能当作窗口独享峰值或普遍资源上限。

首组 6,000 文件扫描不到一秒，开启时有预热样本，但扫描窗口没有采样重叠；保留 `small-scan-observation.json`，不作开启采样期间的性能结论。随后扩大到 30,000 文件、60 目录及一个所有权标记，四个全新主窗进程在同一夹具按 off/on/on/off 完整扫描，见 `scan-probe.json`：
