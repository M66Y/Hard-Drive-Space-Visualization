# 第 5 轮背景设置收尾

基线为 `bd6c9f8941a291a77f2a0d4df4eec66fca9af56a`。接续并审查上轮未提交的背景实现，用户已确认按审计计划先完成背景、再修复异常日志隐私。本目录仅记录背景部分，后续隐私修复单独提交。

## 实现与决策

- 主窗背景设置支持 PNG/JPEG/BMP、缩放、拖动/数值焦点、自动/手动强调色及恢复默认。恢复默认先预览，应用才写入，取消保留旧配置。
- 预览含浅色数据面板、正文、按钮和进度颜色，主窗进度随强调色同步。默认主题仍保留红橙进度，文件类别颜色保留原语义，数据区有浅色底。
- 导入上限 24 MiB、4,000 万像素，处理副本最长边 2,048 像素。按 EXIF 方向校正，副本不保留原图路径和方向元信息。EXIF 语义参考[微软 GDI+ 文档](https://learn.microsoft.com/en-us/windows/win32/gdiplus/-gdiplus-constant-property-item-descriptions)。
- v2 配置包含长度及 SHA-256 校验，读取兼容早期 v1 预览。编码完成后写同目录临时文件、刷新到磁盘，再替换旧配置；失败保留旧数据并清理临时文件。恢复只删除软件副本。
- 读取/默认预览在后台运行，可关闭或取消，迟到结果释放。保存阶段禁用调整与关闭，避免界面取消但配置已提交的矛盾；完成后才交接图像所有权。关闭/释放期间不再操作控件。
- 为主窗增加可注入的设置路径，默认生产路径保持软件用户数据目录；测试不触碰个人配置。普通开发入口统一为 `bin/Release/net9.0-windows/DiskAtlas.exe`。

## 验收与健壮性

应用和测试普通 Release 构建均 0 警告、0 错误。最终 `--background-tests` 与 `--background-tests --dpi-96` 各 7 组通过；`--ui-regression` 与 `--ui-regression --dpi-96` 各 10 组通过。实际主屏 144 DPI，96 DPI 使用独立虚拟化进程。

专项覆盖配置截断、校验失败、未知版本、非法数值/标记、v1 兼容、文件被锁时保存/重置/读取失败、旧数据保留与重试、极端长宽比、拒绝 GIF、取消、8 种 EXIF 方向的尺寸和角点。真实弹窗控件覆盖应用、取消、默认预览、失败提示和两种尺寸。通过延迟导入验证重复操作隔离、关闭后迟到位图释放。

每次专项另起四个进程，使用生产主窗 `loadSavedBackground: true` 链路与隔离目录，覆盖两次自定义启动、默认重置启动、损坏配置回退。源图删除后仍恢复裁切与颜色。测试以链接的生产主窗代码启动，不向正式程序增加验收命令行开关。

使用 computer-use 技能观察实际主窗与弹窗，操作系统选图框、缩放、焦点拖动和应用，核对深色合成背景的文字可读性与组件颜色。未保存含个人桌面内容的原始截图。窗口关闭，演示数据收尾删除。

审查确认取消源、位图和临时文件有对应释放，保存与预览不并发访问同一 GDI+ 图像，状态提示不包含原始异常或原图路径。未进行真实跨屏切换、系统高对比切换、耗时量化或逐帧冷启动观察。GDI+ 解码不能在调用中强制中断，取消后不回写，返回结果立即释放；保存的文件系统调用期间需等待，不承诺固定毫秒上限。
