# 发布资产文件名统一

日期：2026-11-11；基线：`d8ea50b`。用户要求继续后续开发，按此前建议先修复通用发布流程中的文件名问题。

## 范围与决策

GitHub 将资产名的空格转成点号，曾导致 v1.5.0 草稿的下载校验失败。后续打包直接生成 `AsukaLens.vX.X.X.zip`、`.exe`、`-source.zip` 和 `-source.tar.gz`，清单及中英文下载模板同步。Release 标题仍为 `AsukaLens vX.X.X`。这是文件名规则调整，不改变软件或安装身份。

旧空格名称仅保留本地验证兼容，上传入口在网络调用前拒绝旧名称；本地验收要求四类资产全部采用同一命名。离线工具保持 Windows PowerShell 5.1 支持。历史快照、旧候选和 v1.5.0 远程资产没有修改。

## 关键文件与验证

- 发布工具：`New-Release.ps1`、`AsukaLens.iss`、`Release.Common.ps1`、`Test-Release.ps1`、`Upload-Draft.ps1`。
- 验收工具和脚本：`Acceptance.Common.ps1`、`PackageAcceptance.ps1` 及对应测试；同步项目规则、发布说明及模板。
- `ReleaseScripts.Tests.ps1`：50 项通过。
- `ReleaseNotes.Tests.ps1`：48 项通过，包括新版本拒绝旧空格 URL。
- `DraftUpload.Tests.ps1`：109 项通过；真实上传脚本通过离线 CLI 替身验证，该替身现在会把上传名中的空格改为点号，覆盖上传、续传、校验、异常和状态冲突；旧名称在任何 GitHub 调用前被拒绝。测试不连接 GitHub。
- 64 位 Windows PowerShell 5.1 的 `OfflineAcceptance.Tests.ps1`：105 项通过，覆盖旧名称、新名称完整核对及提取、混合命名拒绝。
- 重用本机已有候选，分别以原名称和点号名称运行真实 `Test-Release.ps1`；均核对四资产、319 个源码文件和 283 个载荷文件成功；混用名称被拒绝。仅复制既有文件及生成临时清单，没有编译或安装新软件包。临时副本已清理。

保留清单哈希、版本和源码提交绑定、草稿状态保护、已有资产哈希冲突拒绝及失败清理。未改取消、扫描和用户数据逻辑。名称选择函数用于本地兼容，实际资产仍由完整四名称集合和内容校验约束。离线测试不能替代下一份发行安装器的运行检查或真实远程上传；本轮没有打包、创建标签、上传或公开 Release。
