# C75 十万文件顺序对照

2026-11-27，基线 `fc89677`。用户明确许可在一枚新建的 1 GiB 隔离盘内生成十万合成文件，在该盘上依次创建最多两个临时快照并读取必要的 NTFS 原始页。计划顺序为快扫、普通、普通、快扫，同一个普通权限测试进程使用真实主窗。

前三轮完整返回，两组相邻结果比对一致。第四轮快扫报告 `PermissionDenied`，整组没有通过比较。前三轮计时只作诊断，未形成反向配对、稳定提速或整盘结论。

测试助手未获得末次快扫的清理凭证，因此没有自行卸载。回收前使用管理员权限复核本轮镜像、磁盘、分区和卷身份及夹具双份标记，确认计时进程已退出且该卷无残留 VSS 快照，随后卸载并删除本轮镜像。查询只用于确认测试卷状态，没有删除任何快照或启动追加扫描。退出码、初始保留状态和最终清理状态分开记录。

四轮报告校验覆盖三种相邻顺序，支持差异早停，独立验证每个已返回的快扫样本及其清理信息。旧两轮模式保留。相关检查共 606 项，测试构建零警告。实际阶段时间及资源数据仅保存在本机忽略目录，脱敏摘要和可恢复补丁归档。生产代码、默认扫描路径和发布产物保持现状。
