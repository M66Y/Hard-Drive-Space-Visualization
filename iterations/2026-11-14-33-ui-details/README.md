# C33 第一阶段五项界面细节修正

2026-11-14，Git基线`9ac1f0b`，承接未收尾的C30–C32工作区。用户明确提出五项修正，范围见[实施方案](../../docs/ui-five-detail-repair-plan.md)。本轮实现、本机必要回归和真实预览已完成，等待用户效果反馈，不代表第一阶段整体接受或发布。

## 本轮改动及原因

1. 列表横纵滚动条保留原生实例、滚动范围、拖动、点击、键盘和可访问性，仅接管外观。轨道复用列表固定底图，滑块保持可辨识的浅暖色；高对比退回系统绘制。外观重画需配合C32列表局部滚动事务，不能绕过其暂停状态或重新引入灰底与割裂。
2. 完整模块边框采用共心圆角和半笔宽内缩。父框对子内容应用内圆角交集，避免子窗口后绘制盖住父边框；嵌套模块重建自己的区域后会通知父级重新求交，移出父级时恢复自身圆角，重复布局复用有效裁切。不是统一加深边框颜色。
3. 普通“大文件”说明不再在路径栏与分析标题之间插入额外行，匹配数量移至现有列表说明的可访问描述和提示，保留“含子目录”和最大500项的范围表达。部分快照、未读全、未知占用及排除等异常事实仍按共同规则显示，不能为统一布局隐藏统计边界。
4. 路径框与搜索框的整个框体及原生编辑区统一为`Theme.Surface`浅暖白底。此前按各位置壁纸取平均色，形成不同的粉色块；焦点现在只强化完整圆角边框。原生输入、IME和可访问性保留，组合框维持其既有背景策略。
5. 总量未知的进度移除45DIP彩色短拖尾，仅图标沿透明轨道往返并使用缓存的暖色软泛光。确定百分比的已完成轨道、未知／估算文字、减弱动效及取消等状态保留，不生成虚假百分比。

已获用户认可的1.15倍沿边柔光不变。C32列表滚动此前已通过用户验收；本轮需要确认外观接管与工作区切换没有使其退化。最小化恢复黑块继续暂缓，不借本轮修改重启其全局绘制试验。

进度专项首次失败源于合成控件的物理高度没有随DPI缩放，修正夹具尺寸后通过，未放宽像素标准。嵌套裁切首项曾因默认`Margin=3`，测试局部点已落在父边框保护带内侧而误判；改用`Margin=0`的真实贴边夹具后通过，生产裁切几何未扩大。

最终完整UI回归默认144／96 DPI分别19.133／15.495秒通过，未扩大原45秒预算。实际144DPI最小／常用窗口已展示；最小窗口实际切入、切出大文件，常用窗口也切入大文件，路径栏与分析模块间不再增加普通说明行；已观察统一输入框、完整模块轮廓、原生滚动条外观和移动图标暖晕。静态画面及合成断言不能替代用户连续使用的观感，已询问五项效果，等待反馈。

测试预览新增`--unknown-progress`：只把自有进度控件置为未知，并在页脚明确标注“合成未知进度／非实际扫描”；它没有请求个人卷、VSS或提权。调用如`--stage-one-preview b --scroll-fixture --unknown-progress`，最小窗口另加`--minimum`。C33新增专项入口为`--input-frame-surface-tests`、`--progress-marker-tests`、`--workspace-layout-tests`、`--scrollbar-surface-tests`，各加`--dpi-96`复验。
