- `scripts/release/Release.Common.ps1` / `Test-Release.ps1`：安全路径、链接拒绝、清理边界、ZIP/tar.gz 逐文件一致、包内运行时与许可、安装器元数据及输出完整性。静态校验不冒充运行验收。

- `Program.cs`：增加进程生命周期的命名互斥体，供安装/卸载检查，不禁止多开、不结束进程。扫描、统计、背景和诊断逻辑没有改变。

- `tests/ReleaseScripts.Tests.ps1`、`ReleasePackageGuards.Tests.ps1`、`PackageAcceptance.ps1`、`PackageSmoke.cs`：脚本边界与真实本机包验收。包内生产 DLL 在包内 CoreCLR/WinForms 上运行，测试数据和设置隔离。
- `docs/releasing.md` 和待填写的验收模板说明正式门槛；中英文 README、项目状态/计划、AGENTS 和使用说明同步。许可署名沿用 `AsukaLens — M66Y`，未变更许可证。

## 验收发现与修正

最初只比较相同载荷，不能证明已覆盖字节的恢复。加强为“先改写、再失败”后发现 Inno 原生回滚不恢复旧文件；补充逐文件备份与失败恢复。首次补充仍失败，定位为 `CurrentFilename` 含未展开的 `{app}`，改用 `ExpandConstant` 后最终 21 项通过。失败结果不计入通过记录。

备份仅保存被替换的原程序文件，普通失败后恢复，成功后逐项删除本次备份，不递归清理安装目录。恢复失败或进程强制中断时保留本地备份和路径映射，后续安装停止并提示检查；不声称保证断电或强制终止后的自动恢复。

验收宿主还修正了包内依赖解析，以及 SW_HIDE 导致 WinForms 首帧 GDI 错误的问题；最终用正常窗口和隔离设置运行真实程序集。安装器版本信息带填充空格，校验改为清理产品名空格并比较数字版本字段。上述均通过最终复测。
