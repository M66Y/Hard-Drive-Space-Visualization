## 实现与本机结果

从官方 `cli/cli` v2.103.3 获取 Windows x64 ZIP 和官方校验文件，核对两份下载摘要、ZIP 条目摘要及解压后 EXE，信息保存在 `scripts/release/github-cli.json`。必要工具保留于 Git 忽略的 `artifacts/release-tools/gh-2.103.3/`，共两个文件、41,786,233 字节；未修改系统 PATH，不纳入 Git 或软件 Release。

用户本人完成登录后，实际核对认证成功并使用 keyring 系统凭据存储。CLI 能读取目标仓库，返回 `permissions.push=true`，Release 清单为空。没有通过创建草稿/上传资产探测权限，没有读取令牌，没有在归档中保留设备码、认证原文、账户配置或本机路径。登录时选择不接管既有 Git 认证方式，CLI 本身配置为 HTTPS 协议。

新增 `Test-GitHubAccess.ps1`：核对命令参数、认证、仓库读取、报告的推送权限和分页 Release 清单；原始子进程输出只在内存中处理，返回固定字段和状态，`upload_tested` 始终为 false。PATH 无 `gh` 时，共用解析器可使用经过固定哈希核对的便携工具；修改或缺失时拒绝。

准备过程中查到该 CLI 版本默认支持遥测；首次版本/帮助探查在发现该行为之前，未测量这些早期调用是否产生遥测，不宣称整个准备过程从未发送 CLI 遥测。随后的认证、真实探针及项目上传调用显式关闭 `GH_TELEMETRY`；上传结束或失败恢复调用者原值，探针按子进程配置，不修改用户级/系统级变量。没有改变 AsukaLens 应用自身的本地隐私行为。

关键文件为上述探针与 pin、`Release.Common.ps1`、`Upload-Draft.ps1`、两份相关测试及 CLI 替身、[工具手册](../../docs/github-publishing-access.md)和受影响的规则/状态/发布说明。程序源码、版本字段与四类资产未改变。

## 验证与健壮性

- `tests/GitHubAccess.Tests.ps1`：17 项通过。复制未经修改的生产脚本，以本地合成可执行 CLI 覆盖未登录、无推送权限、查询失败、非法 JSON、缺参数、分页计数、私有原文不进入报告、备用工具缺失/篡改。合成 CLI 不联网，不实现写命令。
- `tests/DraftUpload.Tests.ps1`：74 项通过。每次 CLI 替身调用要求遥测关闭，全部正常/失败调用后核查父环境保持原值；原草稿状态、续传、冲突和下载验证回归通过。
- `tests/ReleaseScripts.Tests.ps1`：48 项通过，包含新增脚本语法检查和既有快照/路径/清理保护。
- 实际 CLI 只读前置检查通过，凭据存储来源另行只在内存中核对；合成回归与真实访问分别记录，不称为真实上传验收。

探针按固定阶段报告失败，单个子进程超时 30 秒时只终止该探针创建的子进程。此超时分支为代码审查，未另行制造超时实测。诊断对象不是发布门槛批准文件；它的进程退出码也不能代替具体状态字段。
