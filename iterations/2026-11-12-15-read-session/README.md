## 目标与界限

本模型约束“什么情况下可以结束一次模拟收集”，不是MFT读取器、真实来源证明或整卷覆盖证明。ControlledFixture与ValidatedImmutable只是注入的合成断言，当前没有实际VSS验证器；LiveUnproven即使两次映射相同、NoNewUsn=true也不能Complete。

实现分为模型、核心场景和独立反例三份文件。批次全或无；全会话累计4096记录预算不会因重启返还；最多2重启；所有异步入口带expectedGeneration；旧代/未来代不改变当前状态；取消/拒绝/完成终态不被迟到结果覆盖；unknown保留空值和计数；已知总和溢出拒绝，不发布部分结果。

审查补齐三类容易漏掉的组合：等待重启时继续累加后来的映射/增长要求，最终proof中更高的epoch/映射/长度不能回退；错binding批次作为协议错误直接拒绝，不冒充新proof；Count/indexer重入取消或通知后立即停止取项，复制期嵌套Accept/Complete/Restart不能发布在途前缀或复活取消。单纯重复/乱序的同绑定重扫与真正来源变化分别处理。

未知值的已知部分与未知计数分别报告，对应Total保持null；这不是生产统计口径或硬链接归属算法。SourceStamp是模拟重新验证epoch，不是恒定卷ID；模拟条件本身不证明来源真实不可变。

本轮不运行VHD或系统探针，不新增原始记录、日志或模拟路径持久化。没有生产程序集、七项产品功能或发行资产改动。
