## 实现与边界

原型全部位于 `tests/Prototypes/Ntfs/`，测试入口 `--ntfs-prototype-tests`。仅编入测试项目；应用项目继续排除 `tests/`，未增加运行时依赖或生产扫描分支。

- `NtfsRecordDecoder.cs`：解析有界合成 NTFS 3.1 FILE 记录，校验 USA 修复、属性布局、Unicode、数据长度、runlist、VCN/LCN 和普通分配簇几何；完整文件引用来自外部槽号加序列。
- `NtfsPrototypeIndex.cs`：分开文件对象与目录入口；逻辑大小按入口累计，实际占用按对象去重；保留未知大小，拒绝冲突、目录循环、槽位复用、容量越界和总量溢出。
- `NtfsRecordFixtures.cs` / `NtfsPrototypeTests.cs` / `NtfsIndexTests.cs`：内存合成记录、边界检查、固定种子有限变异、取消前与构建中途取消，无磁盘镜像或真实名称。
- 特殊压缩/稀疏分配、加密/重解析、属性列表/扩展记录等明确标记待补查；尚未实际补查、拼接或回退。驻留数据分配 0 只表示独立数据簇为零，尚未对照真实 NativeStorage 语义。完整限制、容量和来源见原型 README。
