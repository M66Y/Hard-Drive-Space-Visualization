# C63：透明滚动条拖动与滑块几何同步

2026-11-22，基线`5e07a71803fe9e0c83334678276797326997c3b1`。用户要求修复搜索结果列表滚动时的系统灰轨道和闪动，明确批准仅接管原滚动条指针操作，保留布局、背景、动效、原生范围/键盘/滚轮及可访问身份。没有录屏、改变系统设置、个人卷操作、打包或发布；第三阶段仍只有方案。

## 结果与原因

静态皮肤及单步消息不足以阻止原生鼠标跟踪循环直接绘制灰底。现在在原条上处理拖动、箭头和轨道，仍经原Scroll事件交付位置、尊重处理器修改后的NewValue；保留系统全拖动偏好，未启用时只预览滑块，松手提交。高对比和必要资源不可用保持原生回退。

第一版通过后台检查后被用户拒绝。第二段视频暴露滑块回跳，独立横向程序位置测试随即失败：禁止即时原生重绘会使缓存几何不更新。现把原条WM_PRINTCLIENT送入私有DC刷新位置/长度，再覆盖完整主题背景、滑块和箭头后发布；系统中间像素不出现在条窗口。每条缓存最多262144像素（1MiB），纳入既有预算；复用、隐藏/尺寸/句柄改变及关闭释放。

最终还用测试对象偏好注入暴露延迟模式释放捕获时的旧值中间帧。原断言失败后改为ThumbPosition提交→释放捕获→EndScroll，不修改Windows设置。事件边界、取消、失捕获和重复计时器释放保留。

## 实际体验与验证范围

几何版完成16组受影响检查（两档指针/表面、C57列表滚动/缓存/完整UI、选择联动、布局与默认入口）。实际正常版在自建140文件目录中检查顶部→底部→顶部拖动后，用户明确反馈“这次正常，可以保留”。用户随后正常关闭，授权合并最后的松手边界修正；合并版两档各42项指针、34项表面和完整UI共6组通过，已重新打开同一演示目录。不再要求重复验证已接受的几何效果。

应用与测试构建通过，C55独立DLL哈希保持不变。没有改变背景聚焦/Zoom、字号、1.15倍持续沿边柔光、C57默认/C55回退、扫描统计或七项功能。横竖方向、RTL/大范围、筛选后长度、位置同步、事件调整、取消/失捕获、隐藏/关闭资源已列入断言。最终额外延迟边界主要依赖自动反例/复验，不冒充另一轮人工验收。

自有窗口早期离散采样：旧版2个捕获样本有1个轨道变化，单靠补画仍2/1；指针候选1/0。样本过少，不代表帧率、发生概率或DWM最终呈现。初版16组通过对应已被用户拒绝的版本，不与后续16组和最终6组混为同一视觉结论。

Windows10新绘制与真实跨屏仍未验；静态GDI像素、96DPI进程和本机用户通过不能外推所有设备。既有高对比回退保留，不宣称本轮已人工验完所有辅助技术。

## 保留的失败与健壮性审查

本机保留无条件几何查询造成消息重入的栈溢出、隐藏缓冲未释放、禁用人工Down、位置几何、强制延迟松手断言失败，以及受限NuGet配置读取和旧进程锁定构建失败。每项按实际原因修正后原断言复验，未抹掉早期失败；受限配置复验未引入依赖安装。视频解码中间物已删除，原用户视频不动，不上传原始帧、路径或文件清单。
