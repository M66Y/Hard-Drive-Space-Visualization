# C59：修复高 DPI 背景额外放大

2026-11-21，基线`48c8397`。用户反馈正常版背景焦点不对、人物脸不可见。修正版真实窗口已展示，用户确认：“符合预期，保留这次修复”。本项通过，不自动确认整个第一阶段结束或进入第二阶段。

## 原因与修复

C55与当前版在相同隔离配置和尺寸下构图一致，不是C57独有的焦点变化。独立标记图与生产绘制反例确认：窗口背景已被裁切为所需像素尺寸、缓存分辨率为96 DPI，但`DrawImageUnscaled`按物理尺寸绘制，在144 DPI目标上又多放大1.5倍，右侧人物被挤出窗口。微软对该API的[物理尺寸契约](https://learn.microsoft.com/en-us/dotnet/api/system.drawing.graphics.drawimageunscaled?view=windowsdesktop-10.0)与本机标记图结果一致；边缘插值使64像素样本约96像素覆盖中的95列为实红，不据此放宽产品像素比较。

仅将背景缓存的GDI+回退发布改为完整源/目标矩形显式像素映射，维持原裁切与图形裁剪。没有改图片、默认/自定义焦点、Zoom、用户配置、布局、字体、透明度、动画速度或C57合成架构；C55独立二进制保留。
