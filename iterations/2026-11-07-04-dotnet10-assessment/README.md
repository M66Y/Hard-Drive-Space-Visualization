# .NET 10 迁移评估

用户要求开始后续任务。本次按开发计划先完成运行环境迁移评估，基线 `4e6c07f349fd858a756e9674ef5f81dd28a8f73c`，不自动展开完整日志系统及其他方向。

关键文件为 `docs/dotnet10-migration.md`，包含官方支持依据、本机环境摘要、两种 SDK 使用方案、源码兼容性核查、验收要求与回退基线；`docs/development-plan.md` 同步当前阶段。

核查两项目目标框架、SDK / Runtime 清单、构建脚本硬编码路径、无第三方依赖状态，以及 GDI+ 错误捕获、DPI/首帧、剪贴板/拖放、原生调用和背景子进程测试入口。现有绘制与图片错误处理已覆盖 .NET 10 调整后的 ExternalException，但尚未在新框架编译或运行，不能据此宣称兼容。

仅修改方案文档，未安装 SDK、修改系统环境或产品代码；不重复既有 .NET 9 回归，不打包或发布。依赖大版本按 AGENTS 的流程先选择环境方案，建议项目内隔离 SDK，待确认后实施。

本轮检查文档事实、相对链接、改动范围和隐私。`changes.patch` 保存两个方案文件相对基线的变更；`files.json` 记录文件清单、LF 规范化 SHA-256 与独立基线补丁恢复结果。没有保存本机完整环境输出、原始日志、用户设置或个人路径。

只创建并清理本轮补丁验证临时目录；源码、当前应用、旧预览与正常依赖保持原状。文档验证后提交并推送 main；提交结果以 Git 历史及交付说明为准，迁移实现仍待用户选择环境方向。
