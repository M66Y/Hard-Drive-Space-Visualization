# 第 3 轮：实际刷新方式与日志诊断

日期：2026-11-03。基线提交：`6f8cee18c169bdc7f6f8b3eccf245ed5b68bc690`。

## 范围与结论

用户批准先诊断现有 NTFS 日志路径，修正能修正的只读兼容问题，展示实际刷新方式、降级原因和工作量，并核对刷新与完整扫描结果。保留七项产品功能、统计口径、硬链接、取消和缓存失效规则。没有创建服务、持久缓存、系统日志或请求管理员权限；没有进入背景、日志系统或整体视觉改版。

本机元信息卷句柄可打开，但日志查询返回错误码 1；同一进程尝试普通只读句柄返回错误码 5。因此本机实际刷新仍核验全部目录和文件元信息。本轮提高诊断真实性、读取兼容和连续性检查，**没有解除无日志时的全量核验限制，也没有证明本机刷新提速**。

## 关键决策与文件

- `ChangeJournal.cs`：先用元信息句柄，再尝试同一权限下的只读句柄；分别保留失败类别与错误码。查询游标一次后交给协调器，绑定当前卷，拒绝嵌套挂载造成的卷混用。读取协商 V1/V0 及现有句柄上的非特权/标准接口；不等待未来数据或文件关闭，接受 V2/V3 记录。检查返回长度、游标推进、记录顺序、日志 ID、截断、回退和读取后的连续性；未知格式或超过 200,000 条记录保守回退。
- `ScanCoordinator.cs`：明确选择完整扫描、日志增量或元信息核验。扫描开始游标在任何进度回调之前取得，后续写入留待下次重放；缓存只在本次进程内，不保存到磁盘。旧结果不完整、身份异常或准备失败时完整重扫。扫描准备、核验和读取整理耗时分开记录。
- `RefreshStatus.cs`、`ScanPolicy.cs`、`Core.cs`：类型化方式、日志状态和数值计数。公开诊断仅保留稳定原因、错误码、阶段及工作量，不展示原始异常、文件路径或卷标识。原有 Incremental 字段保留兼容，但界面不再用它推断日志是否可读。
- `MainForm.cs`、`ScanProgressControl.cs`：准备阶段标记“检查刷新条件”，未知总量不显示虚构百分比。顶部展示实际方式、重扫/复用数量和详情入口；点击文字或右键重新扫描可查看最近完成扫描的原因、日志状态、记录数、核验目录/文件、重扫/复用及分阶段耗时。保留强制完整扫描。
- `tests/JournalRegression.cs`：16 项新增协议与回退检查；`tests/RefreshBenchmark.cs`：明确分开真实接口、元信息路径和模拟连续日志。既有功能/界面检查更新阶段与实际方式断言，避免把“复用”打印成“真实日志可用”。README、使用说明、工作规则事实和历史记录同步。

## 验收与健壮性

- 应用 Release 构建至 `bin/Preview`，测试项目 Release 构建，均 0 警告、0 错误。
- 38 项核心 + 25 项高级 + 16 项日志检查全部通过，共 79 项。涵盖新增/删除/目录移动、保留时间戳的深层修改、目录替换、范围外硬链接写入、持续打开写句柄、扫描期间变更重放、取消隔离、日志断档和错误传播。日志协议检查覆盖 128 位身份、协商复用、畸形记录、游标停止、日志重建、卷不符和处理上限。
- 根目录被替换不复用旧身份；旧快照缺失身份时完整扫描，并明确是快照问题，不把成功日志读取误报为失败。没有有效旧游标时先核验；模拟连续无变化日志可以零枚举复用，完整快照逐项保持一致。
- 6 组 WinForms 集成检查通过，实际 DPI 144，覆盖已有预览、取消恢复、占用、策略、刷新、强制扫描、进度/动效及缓存。新增检查打开真实详情窗口并读取原因/计数，核对界面实际刷新方式。
- 暂停前的一次界面测试超过 45 秒，没有计为通过；本次单独重跑通过，最终代码再次单独运行也通过，未增加超时掩盖失败。较早的基准可能与界面检查重叠，不用于性能结论。
- 外部桌面控制的截图与控件状态不一致，重新连接仍未恢复，未完成新增详情窗口的外部视觉验收。程序内详情交互检查已经通过，不将其描述成截图验收。开发预览保留供进一步检查。
- 当前进程无法验证真实可读卷日志路径；此路径由模拟协议/协调器检查覆盖。没有拿模拟通过代替真实日志可用，也未测试其他文件系统、权限、DPI 或跨屏组合。退出后缓存丢弃，程序离线期间的变化由重启后的完整扫描处理。

## 刷新对比

同一组 2,400 个小文件、61 个目录；HighSpeed 策略，暖元信息缓存，一轮预热后按四种轮换顺序及其反向各 8 次。每次与完整扫描逐项比对相对路径、两种大小、修改时间、计数及未知/不完整/共享状态，全部一致。创建样本和逐项比对不计入测量。最终基准单独执行，没有同时运行本轮构建或界面测试；未控制其他后台负载，也未清空系统缓存。
