# C74 隔离盘完整 NTFS 快扫端到端测量

2026-11-27，基线 `039759e`。用户明确批准新建并格式化一次性 1 GiB VHD、在该测试卷创建一个临时 VSS 快照，以及读取所需的 NTFS 原始页。测试仅使用约一万个人工生成的固定文件，按快扫、普通自动策略的强制完整扫描各一次运行。

两路范围、身份、两种大小和排除项的比较通过，快扫使用生产权限助手且无回退，退出码为 0。两次测量均从普通权限主窗发起扫描，直到完成查询和同步最终绘制。快照清理、测试盘卸载及镜像删除均已确认。

该组普通扫描更快。快扫中最大的单段为权限确认与助手启动，其耗时无法细拆为人工等待和系统启动。普通在第二轮运行，缓存影响尚未分离。仅以本次结果判断这份合成数据的两次等待时长。整盘稳定收益及更大数据量上的表现待验证。

相关检查合计 1608 项，另验证了缺失准备参数时拒绝运行，测试构建零警告。测试路径复用既有生产协调器、主窗及输出指纹。新助手通过本机管道绑定同一用户的两端进程，只发送本轮夹具路径。终态或快照清理未知时，保留隔离镜像待确认。首次启动曾因授权描述不足在执行前被自动审批拦截，明确授权后只有一次实际运行。

生产源码、默认快扫选择及发布产物保持现状。公开归档仅保存状态、固定预算和构建指纹。实际时间、资源采样和阶段细节保留在本机的忽略目录，临时重复结果已删除。
