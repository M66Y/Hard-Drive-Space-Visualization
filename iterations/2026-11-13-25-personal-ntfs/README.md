- 补齐修改时间；原始 `$STANDARD_INFORMATION` 对象时间优先，硬链接不被陈旧的目录时间拆成不同对象。Native 补查只对同一快照的一次对象查询。
- 主窗默认关闭“NTFS 快扫（实验）”。只有完整树且清理已确认才发布；取消恢复旧结果，不触发普通扫描。已确认关闭的不支持/拒权/超限可回退；未确认清理会停止并锁止本进程后续快扫。

- 结果不携带 live 日志 checkpoint，普通刷新不直接复用快照基线；标注快照时点，定位原路径前后台核完整身份。

见 [checks.json](checks.json)。合成与管道测试未访问个人卷或创建 VHD。主窗检查使用合成结果与假磁盘监测器，覆盖两种大小、树图/列表/大文件/类型、搜索、浏览、取消和刷新。控件断言与截图文件产生都不能替代实际画面验收。

本轮发现并修复：大 MFT 的错误全槽规模假设、缺失/硬链接陈旧修改时间、已确认清理的取消误报清理未知、工厂清理异常丢失关闭事实、最小窗口嵌套表格列自动扩张、无法确认清理后继续创建快照、普通权限与提权通信的只本机边界。测试用 Native 首实例冲突实际返回 Win32 231（实例忙），保留拒绝事实，接受 5/231 两种拒绝码。普通恢复构建受环境 NuGet 配置权限影响，使用已有资产的 `--no-restore` 构建通过。
