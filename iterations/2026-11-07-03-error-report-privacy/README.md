# 异常报告隐私修复

基线为背景收尾提交 `1df299a`，完整基线 SHA 见 `files.json`。用户已确认在完成背景设置后修复异常日志隐私。本轮限最小异常报告，不开展完整日志管理或遥测。

## 改动

`ErrorReport.cs` 通过固定类别映射及数值 HResult 生成白名单文本，字段仅为产品、格式版本、UTC 时间、错误类别和代码。不访问异常消息、原始堆栈、附加数据、内部异常或自定义异常类型名。

最近报告保存在软件本地用户数据目录 `AsukaLens/last-error.log`，正常报告小于 512 字节。同目录临时文件写入、刷新后替换旧文件，失败保留旧文件并尽力清理本次临时文件。只在成功时返回保存位置，失败提示未能写入。没有自动上传、操作事件采集或原始异常保存。

`Program.ReportError` 使用这一结果显示对话框，增加重入保护。显示给当前用户的日志位置是软件自身数据路径，不写入报告正文。旧版临时报告不回溯读取或改写。`.gitignore` 增加日志、转储、背景配置及相应临时文件，上传仍检查实际内容。
