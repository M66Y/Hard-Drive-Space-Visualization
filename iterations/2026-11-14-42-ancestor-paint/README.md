# C42：祖先重绘暂停期间禁止列表滚动条直绘（候选）

2026-11-14。继续处理窗口缩放时的黑框、黑块和背景割裂，保留当前布局、背景效果及已确认的沿边柔光。本轮只修复祖先持有重绘时，列表滚动条仍可能直接绘制或打印的边界；不宣布所有黑块已经消失。

## 问题、反例与改动

几何事务可能持有列表的祖先HWND，旧`ScrollbarPaintingPaused`却只检查列表自身。新反例在旧源码下实际失败，固定码为`AncestorRedrawHoldPausesScrollbarPainting`（checks=7）。仅修正这个判断后，WM_PRINTCLIENT仍可能落入原生绘制，第二个反例实际失败，固定码为`AncestorPauseKeepsScrollbarPrintClientBitmapUntouched`（checks=8）。这些计数是失败时的检查进度，不是七项或八项失败。

当前`WallpaperGrid`沿祖先链检查SysSetRedraw，既不创建句柄，也不取得或释放外部重绘所有权；`PresentScroll`复用同一暂停判断，暂停时保留待呈现状态。`GridScrollbarSkin`在收到带有效HDC的WM_PRINT/WM_PRINTCLIENT且被暂停时直接返回，避免fall-through到原生打印。该守卫位于高对比模式fallback之前；未暂停的高对比模式仍交由原生绘制，不修改系统设置或配色。

新增测试使用自有控件和内存位图验证暂停时打印不改变哨兵像素、不重建底图、不提前呈现，也不释放外部祖先持有；解除后由现有父级RedrawWindow/RetryPending完成底图重建与实际Paint。恢复观察前没有用PaintNow/Update强制补画来隐藏问题。HDC与Graphics按原有所有权释放，没有引入后台采样或新缓存。
