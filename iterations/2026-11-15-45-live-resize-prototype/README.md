## 实现

`tests/Prototypes/Resize/` 内五份文件提供纯合成数据、不可变布局快照、完整客户区绘制、单一显式缓冲、原生控件逐项/组合对照及检查。A不含托管子控件或客户区子HWND；B分别加入TextBox、两个ComboBox、现有WallpaperGrid（DataGridView子类），组合时是明确的多HWND结构。

背景复用当前资源和CoverBounds规则，位置/字体/圆角沿用当前主题，图块使用既有密度/面积计算，保留双行名称路径与1.15倍沿边相位。每次绘制使用当前尺寸的快照，完成复制后才发布命中几何；没有抓取/拉伸旧窗口截图。缓冲上限128MiB，旧容量释放后再增长；该计数不冒充整个进程峰值，B列表自身缓存另列。

原型使用固定80项合成数据，没有扫描个人目录、读取用户背景配置、启动权限助手/VSS或保存用户设置。F2循环 A／搜索框／下拉框／列表／组合，F6为每次30秒的**程序驱动尺寸演示**，F7为模拟进度；原型窗口标题明确标识，EOF不自动关闭窗口。
