# C76 十万文件完整快扫与普通扫描对照

2026-11-27，基线 `2e61ccf`。C75 在第四轮权限请求时停止。本轮重新取得许可，只在一枚新建并格式化的 1 GiB NTFS 隔离盘上生成十万固定合成文件，在该盘依次创建最多两个临时快照、读取必要的原始 NTFS 页。

## 实测结果

使用核对过哈希的 C75 测试构建，在普通权限主窗依次执行快扫、普通、普通、快扫。快扫沿用产品默认核验路径，普通扫描使用自动策略强制完整扫描。四轮均返回结果，两次快扫均未回退。三次相邻比较的目录范围、对象身份、文件大小、实际占用和排除情况均一致。两个快照的清理均已确认，此后卸载并删除了本轮镜像。

在这批文件上，两次普通扫描都比任一次快扫更快。两次快扫中，耗时最长的一段都是从请求管理员权限到助手启动返回。此段包含人工确认和系统启动，现有数据无法单独估计人工等待。第二次普通扫描比第一次明显更快，缓存和预热各占多少尚未量化。完整快扫在其他盘上的收益仍需对应的实测证据。
