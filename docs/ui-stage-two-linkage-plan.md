## 目标与判断

优先让“看见大块占用 → 选中准确对象 → 在列表找到它 → 核对详情 → 进入目录或定位文件”连续、可预测。综合早期主界面提示词、用户三阶段观点和后续外观评审：保留背景表现与舒适阅读，信息在主动选择后出现；不恢复悬停气泡、自动解释框或顶部大标题。

当前 `MainForm.SelectItem` 已有图表/列表双向选择、跨页和滚动；`ActivateItem` 已支持目录进入、文件定位及类型明细；底部已有两种大小、路径和修改时间。此次改善反馈和边界，不重复开发这些基础能力。现有选择主要依赖 `MapItem` 对象引用/部分名称恢复，嵌套图块可能没有当前列表对应行，查询切换可能清空选择；这些需在确认后做针对性核查，不能事先宣称已修复。

## 保留边界

- 保留C57默认背景合成、DIB及C55回退，不改窗口缩放链。保留明日香原图、默认/自定义裁切与聚焦、透明层次、暖红浅色、完整圆角、舒适字号、侧栏磁盘卡片和1.15倍沿边柔光。
- 保留现有总体布局：侧栏、工具栏/统计、路径、图表与列表、底部详情和进度。不增加常驻说明行，不因选择/取消选择而挤动分析区。
- 保留七项核心功能、大小口径、硬链接去重、聚合面积、查询范围、取消隔离和旧结果恢复。本轮不改扫描后端、提权、VSS或性能合同。
- 本轮方案不包含自动清理、删除/移动/运行文件、软件占用入口、背景强度、配色/密度开关、最近目录持久化、全套面包屑/历史导航或框架迁移。

## 一个完整操作过程

1. 在空间分布中单击“视频”目录图块：保留当前目录，图块持续沿边柔光，右侧同一对象保持选中并可见，底部显示目录名称和两种大小。没有跳页时不反复滚动已经可见的行。
2. 单击“视频”图块里面的某个文件：保持当前总览和路径，详情改为该文件；当前层列表若只有父目录，只标出“所在目录”，不把父目录伪装成文件的选中行。
3. 用户主动点击“在列表中查看”：进入文件所在目录，用对象身份选中准确文件并滚动可见。后续需要回到总览时继续使用现有上一级/扫描根目录，不自动增加历史控件。
4. 点击文件行：图表反向指出同一对象；详情提供“定位文件”。定位前继续沿用既有路径存在/快照身份核验，不在选择动作中打开文件或资源管理器。
5. 主动点击“详情”：展开一个按需窗口核对完整名称、完整路径、修改时间、两种大小及必要的未知/共享状态。关闭后返回原选择，不增添悬停提示。

第2、3步已由用户于本轮明确选择：“保留视角，主动点击后进入所在目录”。不是待重复确认项。

## 三处的具体行为

| 区域 | 建议变化 | 避免的误导 |
| --- | --- | --- |
| 图表 | 单击只选择，悬停只保留既定动效；双击保留目录进入/文件定位。列表选择反向命中对应图块，若合并展示则指出归属的聚合块 | 不用名称或大小猜测同名对象；不让悬停改变已选对象 |
| 列表 | 当前页内只在目标不可见时滚动；跨页沿用现有定位，页脚明确当前页/总页和定位结果；选中底色保持，另用一次约700ms的轻浅提亮帮助发现 | 不新增深色整圈边框，不让一次选择引起往返跳页或抢走键盘焦点 |
| 底部详情 | 固定两行核心信息：名称/对象类型/两种大小；路径或归属。目录主动作“进入目录”，文件主动作“定位文件”，必要时有“在列表中查看”，统一“详情”入口 | 不把不同对象的名称/路径/大小拼到一起；无选择时动作禁用 |

详情窗口按需承载完整内容，不是每次单击自动弹出。完整路径可选择/复制；修改时间和特殊占用状态集中核对，不塞进常驻小字。对长名称/路径优先省略可见行并保留主动查看，不能靠悬停才能读到完整信息。

## 必须覆盖的特殊对象

- **同名文件：** 以当前扫描代际内的对象身份和路径辨别；不要只按名称恢复。示例中两个 `app-demo.exe` 分属不同目录。
- **嵌套文件：** 按上述已确认方式保持视角，再主动进入。父目录标记是归属提示，不等于真实文件行已定位。
- **合并图块：** 表达“合并N项”，禁用单文件定位。存在可靠成员身份时可映射成员；旧上游聚合没有成员清单时只引导查看当前列表，不推断成员、不承诺新增过滤能力。
- **占用未知：** 显示“未知”或“已知量＋未知”，不当作零，不为定位补查擅自触发整树扫描。
- **硬链接：** 区分文件原生分配量和本路径是否重复计入范围；不把共享项显示成真正零占用，不暗示等于删除可释放量。
- **类型汇总：** 不是文件；动作应为查看明细，不能给文件定位。沿用现有类型→大文件明细逻辑。
- **部分结果/扫描中：** 不能让旧完整结果的选择绑定到新预览对象；未知、跳过和快照事实继续通过已有状态/主动详情访问，不新增自动说明框。

## 交互预览

预览为对话中的独立设计演示，使用默认公开插画、公开演示路径和固定合成对象，不读取文件系统，不调用资源管理器，不修改用户配置。它不是WinForms实现，也不能验收原生缩放或扫描性能。

以当前常用窗口约1440×940的比例展示，背景只按整客户区统一cover，不在图表、列表或详情分别缩放。保持明显背景，不用固定高容器把背景额外放大。窄对话视口可以展开查看；窄屏的预览适配不是产品最小窗口已验证的声明。

可体验：目录选择、内部文件选择、主动在列表查看、双向选择、分页定位、文件/目录/合并项详情、同名文件、未知占用和共享硬链接。复制/文件定位只演示意图，无个人文件操作。

## 确认后如何合并实施

收到预览意见并确认实施范围后，先建立选择身份和来源的一致更新，再接通分页/可见行定位及固定详情区，最后合并状态与绘制回归；不按内部小步骤反复请求确认。所有选择变化使用同一选择快照，异步查询回写前核对扫描/查询代际；已经可见的目标不滚动，快速连续操作只发布最后一次有效选择。

选择和详情不得在UI线程遍历整棵树或执行新的耗时I/O；优先使用现有结果索引。背景缓存、列表局部绘制和原生输入保持现有所有权，不能为行提亮重建整窗背景缓存或加入全窗定时重绘。

实现时间暂估6–10小时，包含开发、相称检查与真实程序展示；不是后台连续执行承诺。若要扩大聚合成员模型或新键盘空间导航，应先解释差异、重新确定范围，不把这些塞进当前估时。

## 验收与停止点

- 固定合成目录验证：单击图块/列表定位同一对象；跨页页码和可见行正确；同名异路径不串；内嵌文件保留视角且主动进入后准确选中。
- 快速点击、排序、搜索、切口径/视图/目录后只显示当前有效对象；被过滤/删除/失效时清楚解除选择或给主动入口，不悄悄清空搜索来强行定位。
- 无选择、目录、文件、类型汇总、合并块、未知、共享和部分结果的详情/可用动作正确；取消后旧结果恢复仍有效。
- 检查键盘Tab/方向选择/Enter的既有行为及可见焦点；不顺带宣称补齐完整二维图块导航和UIA树。
- 默认/96DPI两档UI、名称与脏区裁切、双行列表、滚动、沿边柔光、布局及受影响选择专项；实际常用/最小窗口做完整流程，连续缩放、还原和背景构图不得退化。
- 完成后先打开真实正常功能候选，给用户体验并反馈；未接受前不自动结束第二阶段，不进入第三阶段，不打包发布。
