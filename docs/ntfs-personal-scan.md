# 个人磁盘 NTFS 快速扫描

2026-11-13，实施基线 `fd0639e`。本轮按用户要求先补真实卷来源，再接主窗。以下是本轮合同，完成状态以验证记录和项目现状为准。

主窗口保持普通权限，默认使用原目录扫描。勾选“NTFS 快扫（实验）”后，每次扫描启动同一软件的短时管理员助手；助手只接受经 Windows 核对的同一程序父进程请求，路径与结果通过当前用户专用的本机内存管道传输。启动参数、日志和仓库不保存扫描目录、文件清单、对象身份或原始页。

## 读取与来源

仅接受本地固定 NTFS 3.1 卷的盘符绝对路径，初版支持 512 字节扇区、4096 字节簇、1024 字节记录。逐级核对目录身份并拒绝重解析/跨卷，创建本次短时、自动释放的 VSS 快照；不锁定个人卷、不修改差异区配置、不打开用户文件数据流。MFT 页可能包含相邻未选对象的记录和驻留小文件内容片段，仅读取记录中的必要元信息，原始页不落盘、不上传，作用域结束释放；不能宣称物理上完全没读取正文片段。快照建立后从同一来源核验目录、文件身份、MFT、记录分配位图与必要的 Native 大小。系统在快照存在期间可能因其他写入使用临时差异空间。

大 MFT 不再要求总槽数小于测试盘上限，只读取所选目录需要的记录页和位图页。一次尝试最多 262,144 个目录/文件入口、32 Mi UTF-16 名称字符、4096 个 MFT 页、512 个位图扇区；原始请求合计不超过 257 MiB、8192 次，每次不超过 64 KiB。Native 补查最多 32,768 对象、8 路、队列 128。通信另限 256 MiB、深度 512 和累计相对路径字符，超限不扩大预算。

不支持的格式可以在同一快照上补查；记录损坏、位图未分配、身份/类型/序列矛盾不能由补查掩盖。重解析点、无法完整列举或任何未知大小使快路本次尝试失败，不发布部分树。逻辑大小按入口累计，实际占用按对象去重；目录元数据与删除后释放量不是此口径。

## 发布结果、取消与回退

只有完整结果且本次快照清理已确认，主窗口才替换旧结果。进度先显示明确阶段，未知总量保持不确定进度；不按时间伪造百分比。完成后显示快照时点，刷新重新扫描，快照结果不携带 live USN checkpoint，也不直接作为普通刷新缓存。

用户取消只恢复旧结果，不转普通扫描。拒绝管理员授权、不支持或超限且已确认本次资源清理时，转现有目录扫描，并说明原因。通信中断、助手异常退出和无法确认清理时停止并保留旧结果，不把进程退出当清理证明；本进程后续快扫被锁止，普通扫描仍可选择。定位快照中的原路径前，在后台核对其当前完整身份；目录浏览、搜索、排序、大小切换仍在内存中完成。

初版不绕过目录 ACL，不启用备份权限；重解析点、受保护目录、超出预算或 MFT 属性扩展等格式将触发整次回退。所选可读目录通过不表示所有整盘范围都能走快路。新路径尚待 Windows 10 和更多文件系统形态的实际验证。

## 验证与权限

先运行有界索引、来源、通信、取消/回退和主窗合成回归，再在用户明确允许的真实目录验证。真实文件名、指纹和逐项差异仅内存核对，不写公共证据；公开记录只给出固定成功/失败类别与验证边界，不给出个人目录统计。性能对照应同源、同范围并计入创建/清理成本；已有自有测试盘收益不代表个人磁盘速度。

当前正在请求的个人目录实测尚不等于已授权；以本轮用户答复为准。没有新建 VHD、读取其他个人目录或正式发布的默认许可。
