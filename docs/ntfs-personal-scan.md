# 个人磁盘 NTFS 快速扫描

2026-11-13。C25 在 `fd0639e` 基线上实现实验入口，提交为 `00c9b41`；C26 以该提交完成下述个人卷兼容与部分范围验收。实现、失败过程和验证证据见[本轮记录](../iterations/2026-11-13-26-personal-ntfs-compatibility/README.md)。本次通过的是明确排除重解析点后的已包含范围，不代表完整整盘或所有格式支持。

C27 以 `e7b4324` 接续，开发代码承接 `be21b34`。正常开发 EXE 已实际完成无普通回退、清理确认的 NTFS 部分快扫，真实结果画面也已观察；线程入口及计时口径修正见[接续记录](../iterations/2026-11-13-27-personal-ntfs-ui-timing/README.md)。最终完整 F/O 已运行完毕，但一致性 guard 未通过，不能将当前真实可运行结果当作已验证的提速结论。

主窗口保持普通权限，默认使用原目录扫描。勾选“NTFS 快扫（实验）”后，每次扫描启动同一软件的短时管理员助手；助手只接受经 Windows 核对的同一程序父进程请求，路径与结果通过当前用户专用的本机内存管道传输。助手启动参数、本地诊断和仓库不保存扫描目录、文件清单、对象身份或原始页。

进程入口使用 MTA 进行助手分派，普通界面显式运行于 STA 线程。独立 COM-only 检查中，6 个 STA 新进程均返回 `0x80010119`，6 个 MTA 新进程均成功；修正后正常开发入口真实快扫成功。旧生产失败没有取得实际 HRESULT，因此保留该失败证据，不据此断言所有 `SnapshotFailed` 都来自相同原因。失败界面仅显示受控阶段／类别与安全数字错误码，不透传原始异常消息。

## 读取与来源

仅接受本地固定 NTFS 3.1 卷的盘符绝对路径，初版支持 512 字节扇区、4096 字节簇、1024 字节记录。逐级核对目录身份并拒绝重解析/跨卷，创建本次短时、自动释放的 VSS 快照；不锁定个人卷、不修改差异区配置、不打开用户文件数据流。MFT 页可能包含相邻未选对象的记录和驻留小文件内容片段，仅读取记录中的必要元信息，原始页不落盘、不上传，作用域结束释放；不能宣称物理上完全没读取正文片段。快照建立后从同一来源核验目录、文件身份、MFT、记录分配位图与必要的 Native 大小。系统在快照存在期间可能因其他写入使用临时差异空间。

大 MFT 不要求总槽数小于测试盘上限，只读取所选范围需要的记录页和位图页。C26 的个人卷代码选用固定 `Large` 预算：一次尝试最多 1,048,576 个目录/文件入口、64 Mi UTF-16 名称字符，以及累计 64 Mi UTF-16 目录相对路径字符；文件路径按需组装，避免为每个文件保留整条相对路径。最多读取 16,384 个 MFT 页和 4,096 个位图扇区；原始请求累计不超过 1 GiB＋2 MiB、65,536 次，每次不超过 64 KiB。Native 补查最多 131,072 个对象，仍为 8 路、队列 128。

通信另限 256 MiB、深度 512，并分别限制名称字符与实际存储路径字符。路径预算包括目录绝对路径的根前缀及 issues 的完整路径，名称预算也计入 issues 的叶名；文件完整路径不逐项缓存，因此不能把此预算解释为所有文件完整相对路径长度之和。任一上限不满足均停止该尝试，不临时放开限制。

普通 `Standard` 与历史 VHD 夹具继续保留各自原预算，不因 `Large` 或本轮个人卷验收扩大。受限 `$ATTRIBUTE_LIST` 解析最多接受 64 KiB 属性列表、64 个扩展记录和 1,024 个 run，支持已校验映射中的受限续段；引用、序列、USA、覆盖或映射校验失败仍拒绝，不猜测尚未验证的读取地址。这些格式支持不等于已覆盖所有个人卷布局。

可补查的不支持格式只在同一快照上查询；记录损坏、位图未分配、身份/类型/序列矛盾不能由补查掩盖。未知大小、未声明的漏项或读取矛盾不得改成“部分成功”。逻辑大小按已包含入口累计，实际占用按对象去重；目录元数据与删除后释放量不是此口径。

所选目录内部的重解析点沿普通扫描策略跳过，不跟随或计入其目标；结果明确标为部分完成并声明排除范围，不能把跳过内容算作已知零占用。扫描入口及祖先仍保持严格来源绑定。早期真实尝试的 `IndexBoundary` 失败证据保留，后续通过获准的重解析点策略处理，不改写历史失败记录。

Wire v3 只传排除总数和最多 2,000 条以父目录标识／叶名表达的边界详情，在接收端重建 issues。详情截断时，所有已包含目录保守标为 `Incomplete`；这表示排除范围未能逐项列全，不是声称每个目录都实际存在排除。其余已包含对象仍须通过正常完整性与大小核验。

## 发布结果、取消与回退

完整结果须通过完整性检查且确认本次快照清理后才能发布。只有已声明的重解析点排除可以产生本轮的部分完成结果：已包含范围验证通过、排除边界已声明、清理已确认后才展示，并提供旧完整结果恢复入口。每个主窗口最多额外保留一个旧完整结果及查询上下文；恢复、新完整结果到来或关闭窗口时清除该备份引用，不无限累积扫描树。

进度显示明确阶段，未知总量保持不确定进度，不按时间伪造百分比；完整完成、部分完成、取消与失败分开显示。快照结果显示来源时点，刷新重新扫描，不携带 live USN checkpoint，也不直接作为普通刷新缓存。

用户取消恢复扫描前展示的结果，不转普通扫描，也不清除仍有效的旧完整结果恢复入口。拒绝管理员授权、不支持或超限且已确认本次资源清理时，转现有目录扫描，并即时说明原因。通信中断、助手异常退出和无法确认清理时停止并保留旧结果，不把进程退出当清理证明；本进程后续快扫被锁止，普通扫描仍可选择。定位快照中的原路径前，在后台核对其当前完整身份；目录浏览、搜索、排序、大小切换仍在内存中完成。

初版不绕过目录 ACL，不启用备份权限；受保护目录、超出预算、未支持的 MFT 属性扩展或严格校验失败仍可能触发整次回退。排除链接目标后的已包含范围通过，不表示整个原始范围或所有整盘都能走快路。新路径尚待 Windows 10 和更多文件系统形态的实际验证。

## 验证与权限

最终真实验收由测试 apphost 从 stdin 精确接收当轮指定范围，再经过生产权限助手与同快照校验，不依赖系统文件夹选择框的结果。`personal-ntfs-acceptance-v3` 返回 `passed-partial`：`cleanup_confirmed=true`、`namespace_complete=false`、`included_scope_verified=true`、`reparse_exclusions_declared=true`、`all_included_objects_matched=true`、`raw_budget_respected=true`。这证明已包含对象及其两种大小通过同源对照，明确不证明链接目标或完整原始范围已扫描。

同一指定范围另在快照及元信息建立后，于目录范围阶段主动取消，返回 `cancelled` 且 `cleanup_confirmed=true`。主窗的部分结果、恢复旧完整结果及取消后保留恢复入口在默认／96 DPI 各通过 86 项合成检查；核心 38、高级 25、日志增量 16 项回归通过。C27 已补齐正常开发 EXE 的空间图、列表、大文件、类型、实际占用、排除明细及快照范围的真实画面观察，默认／96 DPI 界面与桌面兼容检查通过。其他取消阶段与 Windows 10 新后端仍待验证；本轮没有正式发布。

首轮后台 F/O 未通过已包含范围元信息／根统计一致性检查，旧 F 又缺少 Coordinator 发布核验，不作为完整产品性能证据。补齐后的 v2 F 已包含该核验；最终两路均完成、无回退、确认清理且未运行额外审计，对照仍以 guard exit 3 停止性能判定，而非扫描失败。结果为 `included_scope_equal=false`、`root_metrics_equal=false`；`exclusions_equal`、`exclusion_details_complete`、`other_issues_absent`、`allocation_known` 均为 `true`。未报告新增、删除、类型、身份或链接数变化，但两路对象的逻辑大小和分配量存在差异，且差异项中有修改时间晚于快照的对象；后者不能证明全部差异均由外部变化造成。本次对照后未追加扫描，没有等工作量证据前不发布提速结论。

修复和真实界面验收已完成；计时合成 58 项和 app／tests 零警告构建通过。用户已确定本轮收尾、下一轮做同快照逐项对照。本轮不再新增快照或扫描，下一轮的具体来源生命周期、范围和预算需另按执行边界核对；该方向选择不等于已完成对照，也不扩大后续读盘许可。

真实文件名、指纹和逐项差异仅内存核对，不写公共证据；公开记录只给出固定成功／失败类别与验证边界，不给出个人目录统计或计时。同快照的已包含对象 Native 审计发生在清理前，其额外成本不能当作产品快扫耗时。性能对照应计入来源创建、扫描、清理、传输和 Coordinator 发布核验，普通路径强制完整扫描，不把刷新缓存与完整扫描比较；受控研究规模上的收益不外推到个人磁盘或 WizTree。测试 apphost 的人工实测入口只在当轮明确许可内使用，stdin 中的指定范围不得写进命令行、公开说明或验收归档。实测阶段停止开发侧写盘，避免改变被测范围。
