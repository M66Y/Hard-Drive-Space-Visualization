# 磁盘活动面板（开发版）

该功能已进入当前源码，尚未包含在已发布的 v1.5.0 资产中。运行开发版后，扫描进度条上方有“磁盘活动”栏，点击“展开”即可采样；初始折叠，不在后台预先采集。

默认跟随扫描目录所在的物理磁盘，也可以从右侧选择“磁盘 N”。多个分区属于同一块物理盘时显示相同指标。面板显示整块磁盘的活动，包含其他进程，不能用来判断 AsukaLens 自己产生了多少 I/O。

展开后显示最近 60 秒活动曲线，以及活动时间、读取速度、写入速度和平均响应。读写单位是 MiB/s（1 MiB = 1,048,576 字节）；响应以毫秒显示。活动时间来自有效的 `% Idle Time` 的补数，不是扫描完成百分比。

面板展开会占用数据区高度；最小窗口下图表与列表较矮，建议收起面板或扩大窗口。更紧凑的小窗口布局仍待优化。

## 状态与边界

每秒由一个后台循环采样，最多保留 60 个内存点，无文件留存、遥测或上传。首次、切换磁盘或最小化后恢复时重新建立基线，先显示“等待采样”。收起、最小化和退出时暂停并释放源，恢复后不把跨暂停的平均值拼成一秒数据。缺值显示“—”，曲线在缺值或时间断档处断开，不补假零。

原生读取卡住时，界面仍按一秒时钟移动并过期旧曲线；超过 4 秒未更新的指标清为“—”，显示“采样延迟”。迟到的旧样本不能重新变成当前值。系统时钟回退会清除不兼容历史，等待新样本。

首版仅支持能够可靠映射的固定本地单磁盘卷；跨盘卷、网络、可移除盘、明确的 VHD/虚拟/Storage Spaces 总线以及无法核验的设备不猜测。手动选择列表同样来自已验证的固定卷映射。未挂载到盘符、没有固定卷的物理盘不保证被列出。虚拟机若把虚拟设备伪装为 SCSI/NVMe，仅靠该接口不能证明它是实体硬件。

计数器缺失、策略拒绝或设备不再可见时显示不可用，不默认提权或修改系统配置。收起再展开会重新发现和连接。收到设备变化通知时重新核验映射；收到系统暂停/恢复通知时暂停并重新建立基线。通知路径已作合成检查，热插拔、磁盘编号复用、跨多显示器、真正休眠恢复及 Windows 10 尚待真实验收；不保证热插拔后仍绑定原实体设备。

## 实现与验证

`src/Monitoring/` 分为原生采样、卷映射、单后台循环和 UI 四个文件。采样使用英文 PDH 路径，在中文 Windows 上避免依赖本地化计数器名称；使用 `DOUBLE | NOSCALE` 保留字节/秒和秒的原始单位。四项按同一实例名组合，独立检查有效状态，拒绝模糊或重复磁盘号。缓冲最多 1 MiB、4096 项及两次容量重试。

映射使用挂载点、卷 GUID 和单一 volume extent 取得物理磁盘号，再核验设备描述符；不遍历文件树，不提取设备型号或序列字符串。快速选择只保留最新请求，一条采样循环串行拥有源，旧后台和已入队 UI 回调均核对版本。退出不等待阻塞的原生调用；其后台所有者完成后释放，原生同步调用中途取消不作即时保证。

当前中文 Windows 11 上已取得真实映射和四项有效样本，并观察展开、手动选盘、折叠暂停及最小化恢复。与任务管理器同一物理盘的近时段观察仅确认低活动趋势相符，采样时间和口径不能据此视为完全一致；高负载与响应时间的同步对照待补。

独立进程的短时资源观测只覆盖后台监测器，不含 UI、扫描或其他应用的前台响应。以 off/on/on/off 各 5 秒窗口测得开启时约 0.93%–0.94% 单核 CPU，生命周期峰值工作集增加约 9 MiB；单核百分比没有除以逻辑核心数。峰值含运行时和初始化，样本短且外部负载未控制，不能据此承诺普遍资源上限。

检查命令及准确结果见[开发验证](testing.md)和本轮迭代记录。原生接口依据：[英文计数器](https://learn.microsoft.com/en-us/windows/win32/api/pdh/nf-pdh-pdhaddenglishcounterw)、[通配数组](https://learn.microsoft.com/en-us/windows/win32/api/pdh/nf-pdh-pdhgetformattedcounterarrayw)、[两次采样](https://learn.microsoft.com/en-us/windows/win32/perfctrs/collecting-performance-data)、[卷映射](https://learn.microsoft.com/en-us/windows/win32/api/winioctl/ni-winioctl-ioctl_volume_get_volume_disk_extents)。
