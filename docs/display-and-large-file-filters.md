# 大文件筛选与显示偏好

这些功能位于当前源码开发版，未包含在旧的 v1.5.0 Release 中。默认保持当前布局、背景构图与动效。

## 大文件筛选

进入“大文件”，点击列表标题右侧“筛选”。“文件大小至少”可选不限、100 MiB、1 GiB、5 GiB；扩展名可从本次目录中选择，也可输入如 `.zip`。条件与名称搜索共同生效：先筛选当前目录及子目录的全部文件，再展示其中最大的500项。列表摘要分别显示展示数和匹配数。

门槛始终按文件逻辑大小判断。排序、图块面积和占比仍按当前大小口径；统计卡和占比分母仍为未筛选的当前目录范围，未知占用不会变成已知零。条件只影响大文件视图，不重新扫盘，也不保存文件名、路径、扩展名清单或搜索词。

切换工作空间或刷新同一扫描根目录时保留条件；成功更换扫描根目录时重置。取消或失败恢复原条件。选中的文件仍符合条件时保留选择，否则清除旧详情。“清除筛选”或筛选窗口中的“恢复不限”可重置门槛与扩展名。

## 显示偏好

原“背景设置”入口新增“图片 / 显示”页。“图片”保留导入、缩放、焦点和强调色设置；“显示”提供：

| 选项 | 默认 | 可选行为 |
| --- | --- | --- |
| 背景显示强度 | 当前100% | 40–100%，降低时增加浅色遮罩，不改原图、裁切或聚焦 |
| 图块配色 | 原有类别色 | 类别分明，图块与侧栏图例同步，品牌强调色和柔光不变 |
| 阅读密度 | 舒适 | 紧凑仅收紧行高、卡片和间距，保留字号、双行名称/路径和完整详情 |

修改可预览，点击“应用”成功后才保存；“取消”恢复进入窗口时的值。“恢复显示默认”不会删除背景或更改图片焦点。单独应用显示偏好不会重新编码或改写背景图片。

显示配置是软件本地数据目录内、与背景配置对应的独立小文件，版本为1、最多4 KiB，只含三个枚举/数值选项。损坏或未知版本回退显示默认值并提示。设置写入先准备临时文件，再逐个替换；普通写入失败会尝试恢复旧文件。若恢复本身失败，会明确提示并保留本地恢复副本，不能承诺两文件在断电或多进程并发下完全原子提交。

核心查询、保存/取消/失败回退、隔离重启和两档UI检查覆盖本轮改动，滚动发布检查同时覆盖强度65%、类别分明和紧凑组合。整体效果已获本机用户认可；没有由此扩大到 Windows 10 新绘制路径、多显示器DPI或所有最小窗口组合的人工验收。没有新增清理、删除、上传或自定义工作区功能。
