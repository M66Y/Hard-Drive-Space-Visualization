- 技术栈为 C# / .NET 9 WinForms，无第三方 NuGet 包。启动本质是本地 Windows 桌面进程，通过 .NET Windows Desktop Runtime 运行，扫描和界面操作不依赖网页服务器。当前发布脚本使用框架依赖部署。

## 已验证的事实

本轮最终代码重新通过核心、高级与日志检查；背景收尾通过双 DPI 的界面与专项检查，后续只改异常报告与测试入口，专项结果继续适用。测试均用合成目录，背景配置指向测试目录，不覆盖真实用户设置。

| 检查 | 本次结果 |
| --- | --- |
| 应用与测试项目普通 Release 配置构建 | 均 0 警告、0 错误；未打包 |
| 核心测试，无参数 | 38 项通过 |
| `--advanced-tests` | 25 项通过，含真实 NTFS 刷新与完整扫描结果一致 |
| `--journal-tests` | 16 项通过，含协议、连续性、身份及保守回退 |
| `--ui-regression` | 实际 144 DPI，10 组通过 |
| `--ui-regression --dpi-96` | 独立 96 DPI 虚拟化进程，10 组通过 |
| `--background-tests` 及 `--dpi-96` | 各 7 组通过，含独立进程生产主窗启动恢复 |
| `--error-report-tests` | 3 组通过，隐私字段、容量及存储失败 |

真实刷新检查报告 `ChangeJournal`、日志 `Available`，重扫 1 个目录、复用 5 个文件，原生错误码为 0。这只证明本机该合成样本的路径可用，不代表所有磁盘、权限或文件系统。

背景专项增加了 v1 配置兼容、v2 完整性校验、截断/非法值、锁定文件模拟保存/清除失败、重试、取消、关闭期间迟到结果释放、真实弹窗控件、极端比例和 8 种 EXIF 方向。独立进程用隔离设置调用生产主窗的 `loadSavedBackground: true` 路径，验证重复启动、源图删除、默认恢复和损坏回退。

使用 computer-use 在实际窗口操作了系统选图框、缩放、焦点拖动与应用，检查深色合成背景的预览及主窗文字可读性。未触碰个人背景配置。没有进行跨显示器、系统高对比切换或逐帧冷启动测量，也未新增整盘性能结论。

异常报告现使用 `ErrorReport.cs` 的字段白名单，只保留产品/格式标识、UTC 时间、固定错误类别和数值代码。最近一份写入本地用户数据目录，失败不谎报成功，不记录异常消息、堆栈或附加数据。见[隐私修复记录](../iterations/2026-11-07-03-error-report-privacy/README.md)。完整日志管理仍待开发。
