# 本地诊断与问题记录

当前开发预览在主窗口“背景设置”旁提供“诊断”按钮。扫描过程中也能打开；诊断窗口不会阻止主窗取消扫描。此功能尚未进入正式发行包。

## 查看与分享诊断

首次运行默认开启最小本地运行诊断。在“运行诊断”页可以按时间、信息/警告/错误筛选，点击一行查看中文摘要。刷新降级、部分完成与失败会明确区分。列表最多显示最近 2,000 条，通过“刷新”读取新的快照。

需要分享时，先勾选记录，再点击“预览导出…”，核对内容后选择本地文件。默认不勾选。预览生成后，新事件不会加入；保存文件与该快照一致。取消不写文件，保存失败保留原目标并允许重试。软件不会自动上传或打开反馈网站。

导出包含可读摘要及受控字段，例如构建版本、临时会话与扫描序号、阶段、策略、刷新方式、固定原因、并发、文件/目录计数、耗时和错误类别/代码。它不包含扫描路径、文件名、文件内容、搜索词、磁盘标识、背景图片、原始异常消息、堆栈和附加数据，也不包含扫描字节总量。读取和导出均重新校验白名单；损坏内容、额外字段和未知枚举不会照抄到导出中。

预览头部会标明队列遗漏、拒绝或无法读取的项、视图是否截断，以及存储是否不完整。拒绝项可能是一条记录或一个无法读取的文件，不能把这个计数理解为扫描错误数。过量事件可能被丢弃；断电或强制结束也可能丢失最后几条，运行诊断不是操作审计或扫描结果备份。

## 开关、清空与容量

取消“开启本地运行诊断”后，停止采集、丢弃待写队列，并等正在写入的操作结束后显示关闭生效；开关跨启动保留。最近异常报告也受此开关控制。关闭不会删除已有记录，不影响主动填写问题记录。设置损坏时暂停自动记录，用户重新选择开关后恢复；保存失败会提示实际状态。

“清空运行诊断…”需要在软件中确认，会删除软件创建的运行日志及最近异常报告，并使旧待写事件失效。问题记录、背景、用户原文件及导出文件均保留。开启状态下之后发生的新事件仍会记录。部分文件被占用时显示部分清除，解除占用后可重试；不会把失败说成已清空。

| 内容 | 本地位置与限制 |
| --- | --- |
| 运行日志 | 本地用户数据目录 `AsukaLens/diagnostics/runtime-*.jsonl`，8 个分段，每段最多 1 MiB，总计最多 8 MiB，保留 14 天 |
| 最近异常报告 | `AsukaLens/last-error.log`，单份通常少于 512 字节，同样保留 14 天，另计于分段配额 |
| 诊断偏好 | `AsukaLens/diagnostics/preferences.json`，有界小文件 |
| 问题记录 | `AsukaLens/diagnostics/problem-notes.json`，最多 100 条且文件最多 1 MiB，先到的限制生效 |

日志过期清理在启动、追加或查看时执行；软件关闭时没有后台清理服务。存储或权限阻止清理时会提示，不能保证被外部程序锁定的文件立即删除。多实例使用同一互斥与设置代次，旧队列不能穿过关闭/清空屏障。日志队列最多 128 条，每条编码最多 1 KiB；磁盘 I/O 在后台执行。诊断存储失败不会停止扫描。

## 问题记录与开发记录

“问题记录”供你主动记录现象、复现步骤和备注，支持新增、编辑、删除。标题最多 100 字符，正文最多 2,000 字符；不按时间自动删除。达到容量上限时需要先整理。保存失败保留已有文件与编辑文字；另一窗口改过同一条记录时拒绝覆盖，需刷新后再编辑。

问题记录可能含你主动输入的个人信息，因此**不纳入运行诊断导出**，也不会自动附加文件、截图、剪贴板或操作历史。分享其内容时需要自行核对。

“开发记录说明”指出 Git 历史和 `iterations/` 的位置与作用，显示当前构建版本；不自动读取本机源码目录或联网抓取开发历史。

## 开发验证

按 README 构建测试项目后运行：

```powershell
dotnet tests/bin/Release/net10.0-windows/DiskAtlas.Tests.dll --diagnostics-tests
dotnet tests/bin/Release/net10.0-windows/DiskAtlas.Tests.dll --diagnostics-ui
dotnet tests/bin/Release/net10.0-windows/DiskAtlas.Tests.dll --diagnostics-ui --dpi-96
```

专项测试覆盖白名单、配额/期限、写入失败、队列、跨进程互斥、清空竞态、设置恢复、笔记冲突和导出一致性。UI 测试使用隔离合成数据；Windows 桌面绘制检查需要可交互桌面。人工验收入口为 `--diagnostics-preview artifacts/diagnostics-demo`，退出后可清理这个专用测试目录。不要把生成的本地数据、导出或个人截图提交到仓库。
