## 本轮修补与验证边界

发现上传脚本此前只验证版本号和中英文标题，过短的说明也可通过；现要求两种语言分别含更新、修复、限制、环境、使用、下载校验、源码许可，核对 Windows 11 x64、实际清单的运行时、签名状态说明、六个准确下载链接及源码提交。占位符、注释或代码块不能充当正文。校验确保必需结构与标识相符；功能描述是否真实、两种语言是否等义仍由发布前人工审阅。

本轮不重建或打包未改动的应用，不重复旧包安装流程；新增说明检查和受影响的发布/上传脚本回归结果见[迭代记录](../iterations/2026-11-07-19-release-readiness/README.md)。本次仅查询远程状态，未安装 CLI、改动系统环境、创建 VM、标签或 Release。签名状态当前为未代码签名，已经纳入模板披露，不把付费代码签名另加为发布硬门槛。

PERF-001 高速模式不能稳定提速、MAINT-001 非阻塞重构和额外视觉打磨继续留待初版后处理。不能通过本轮准备任务自动重启这些优化。
