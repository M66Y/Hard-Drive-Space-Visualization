# 第16轮建议：自有测试卷的真实来源适配器

2026-11-12，代码基线 `fdc5aa040c308ae660dd07604f250e39c55ce2d3`。用户确认本2小时窗口内的重复256MiB隔离VHD后，第16轮已完成受限来源实现与真实验收，见[证据](../iterations/2026-11-12-16-fixture-source/README.md)；不扩展为真实VSS、个人卷或全MFT许可。下文保留选择理由与实施合同，原纯会话模型仍不是真实来源验证器。

## 本轮建议

先把已通过对照的**新建自有VHD、成功锁定、同句柄有限读取、解锁后复核**做成测试专用来源适配器。VSS本轮先完成可行性与资源/清理说明，保持未实现；不直接锁定用户卷，不将布尔值包装成真实快照证明。

- 来源实例只能由现有workspace/nonce/镜像/卷extents/几何/marker守卫通过后，在成功锁定的factory内创建；映射与读取结果绑定同一实例和lease epoch，拒绝跨来源映射、过期结果和关闭后的读取。
- 保留严格record0映射及既有21对象，真实原始读取仍为22条、128次ReadFile尝试/2MiB、每次最多64KiB；不新增全MFT枚举、任意卷/偏移入口或原始留样，不改变原先大小未知语义。
- 明确借用/持有句柄、锁、映射和取消的所有权；读取失败/取消不发布半成品，最后先结束同步调用并释放缓冲，再解锁；只有解锁、Native对象/别名/命名流/卷绑定复核与父进程卸载清理都通过，才生成可分享的受控对照摘要。
- 不将真实记录强塞进现有NameToken模型冒充真实树或完整覆盖。模型与适配器分别验收，来源实例token仅留内存，不输出路径、设备/卷标识、原始引用或字节。

## 验收与回退

纯合成/Native替身覆盖跨来源误用、锁失败、关闭/取消、迟到结果、短读、映射过期、失败优先级与资源释放；必要时复用已验证底层lease，不新增宽松解码分支。真实验收仅在本轮明确同意的新建256MiB隔离VHD中对照既有21对象，沿用经过审查的归属守卫、创建格式化、挂载、停止、卸载与清理流程。每次完成后立即清理镜像，旧6条kernel样本保持原本机范围。

若本轮2小时窗口内获准重复验证，许可也只限本轮自有镜像，不延续到以后；失败不扫描个人卷或改系统日志补救。应用/测试构建与相关NTFS检查按改动选择，文档/隐私审查、每轮恢复补丁与文件哈希、清理后提交main；普通迭代不打包或发布。

## 后续而非本轮默认范围

适配器验收后，再提出来源无关的有界批量读取/覆盖游标与紧凑建树方案；扩大真实槽位范围另行确认。VSS实际快照、差异区设置、主机卷或个人盘操作均不在本方案中。任何原型通过都不能当作整盘提速或活跃卷一致性已经解决。

## 接口边界与测试清单

建议将来源视作独立所有者，而非给已有裸句柄加一个validated布尔值：私有factory在真实守卫通过后打开并持有卷句柄，成功锁定后从严格record0建立私有映射；source token与map epoch均由它产生，不能接收调用方给出的任意设备字符串/物理偏移/映射。旧Live的卷句柄与新owner交接需显式完成，避免锁竞争或解锁后继续使用旧句柄。

真实factory核对固定CaseId与本次nonce数据根的路径，并实际重读Native上下文；后置验证用固定实现，不能由外部Func<bool>声称成功。合成Native替身仅用于明确标记的测试路径，不能据此生成真实来源证明。返回批次仍为暂存，只有来源关闭/后置校验成功才转成有限fixture对照结果；普通Dispose只释放资源，不生成成功结论。

| 边界 | 必要结果 |
| --- | --- |
| manifest/marker/镜像/extents/几何不一致 | 锁定与原始读取前拒绝 |
| 非固定对象或路径越出本次数据根 | 读取文件/原始数据前拒绝 |
| 来源A的token用于B，或关闭后的token | 不发起新读取，不复用映射 |
| 锁失败、短读、严格解析或完整引用不匹配 | 无可发布批次，按所有权释放 |
| 读取中取消、迟到结果、复制/关闭竞争 | 不发布前缀或复活来源；同步调用不能假称被即时抢占 |
| 解锁失败、后置对象/别名/命名流/卷变化 | 不能生成验证成功，失败优先级保留 |
| 正常关闭与重复Dispose | 按顺序释放一次，父进程仍独立核对卸载清理 |
| 摘要字段注入、任意错误文本 | 深层白名单拒绝，不输出来源token、路径或身份 |

实际通过范围、曾发现并修复的边界、真实复验及未验项以[第16轮证据](../iterations/2026-11-12-16-fixture-source/README.md)为准；这份方案本身不替代测试与授权。
