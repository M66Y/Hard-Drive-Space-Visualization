# NTFS 大规模验证与产品接入

2026-11-12，基线 `5209462`。用户要求补齐大规模测试、实际提速验证，并尽快支持个人磁盘和主界面。开发、必要验证和收尾合并；本文是本次方案，不把待验证能力写成已完成。

## 本次交付顺序

1. 增加独立规模验证模式，不修改旧 256 MiB / 4096 槽模式的授权、预算与证据含义。新建自有 1 GiB 固定 VHD，分级生成 10,000 和 100,000 个普通文件，包含多层目录、驻留与非驻留文件及少量硬链接。创建成本与扫描计时分开。
2. 扩展有界批量读取、位图与索引，保留严格解码、未知大小、对象去重、取消和错误恢复。新模式最多 262,144 槽、256 MiB MFT；含 bootstrap/位图的原始请求总量最多 256 MiB + 64 KiB，最多 8,192 次读取尝试；缓冲与名称/字符总量另设固定上限。超限停止，不自动扩大。
3. 同一受控数据上交替运行快速路径与现有完整目录扫描，至少各三次。快速路径包含来源建立、读取、解析、建树、汇总、必要补查及关闭成本；不把单独解析耗时当扫描耗时。记录每次及中位数、进程 CPU、可明确归属的工作集指标，核对入口、对象、逻辑大小和实际占用。未经控制的缓存只能标为暖缓存/缓存未控制，不称冷盘基准。
4. 根据结果确定产品路径。个人活跃卷不能使用测试盘的独占锁卷方式；优先评估同一只读快照来源，主窗保持普通权限，短生命周期助手负责用户主动启动的快扫，拒绝授权、来源不支持、格式不支持或预算不足时回退现有扫描。首次真实快照/个人卷验证需明确来源、权限与数据范围后执行。
5. 有可重复收益、来源一致性与可靠回退后，接入主窗并验证七项保留功能、进度、取消、旧结果恢复及两种大小。未满足这些条件时不提供会被误认作可靠快扫的入口；交付测量结果与明确阻塞，继续解决必要前置项。

## 数据与权限边界

新 VHD、扩大读取预算和十万文件生成须本轮确认。仅格式化本次新建并验证归属的镜像分区，不输入现有盘或任意设备；结束卸载、核对后清理。原始页、位图、记录身份和文件清单仅在内存，公开证据只保留合成计数、阶段耗时及固定错误码。旧原始留样不改动、不上传。

用户已在本轮明确批准上述规模范围。独立入口为 `Invoke-NtfsScale.ps1 -FileCount 10000|100000`，两种数量分别新建镜像。普通文件按 10% 非空驻留、80% 普通非驻留、10% 空文件生成，另有 10 个硬链接入口；这些比例不代表用户磁盘分布。每种算法各预热一次，然后以 MFT/目录、目录/MFT、MFT/目录三对测量。目录基线使用现有八路扫描器，不能拿人为单线程基线夸大收益。Native 补查最多 32,768 对象，名称最多 1,048,576 项、字符与相对路径字符分别最多 32 Mi UTF-16 单元。20 ms 采样的工作集高水位只是观测值，不是未遗漏的绝对峰值；托管总分配量另列，不替代内存峰值。

个人卷只读扫描意图不等于同意锁卷、创建快照、调整差异区或读取文件内容。具体操作前说明并确认；不修改系统日志设置，不自动把主界面提权，不默认扫描个人整盘。VSS 如需要，先在自有卷验证生命周期、取消及仅清理本次对象；不沿用旧轮次许可。

用户随后单独批准本轮另一新建 1 GiB 自有 VHD 的 VSS 验证：少量固定合成文件、短时无 writer 自动释放快照、同一快照内的 Native 大小和严格 MFT 对照，改写自有 live 文件验证快照保持原值。仍不操作个人卷、不改宿主快照或差异区配置。只有本次快照删除与清理确认后才卸载测试盘；超时、缺失或畸形摘要、无法确认清理时保留自有镜像并明确报告，不强制卸载。来源属性和地址只在私有 owner 内使用，公开仅白名单计数、固定阶段与错误码。它是个人卷来源的前置验证，不自动批准个人卷读取或主窗产品化。

## 验收与收尾

合成边界和旧模式回归先过，再运行授权的真实规模测试；失败保留白名单证据并修复，不以缩小数据或跳过统计掩盖失败。测量、独立审查、文档、项目记忆、可恢复补丁、清理和提交合并完成。未获正式发布授权，不打包、打标签或发布 Release。

## 个人卷完整性的接入判据

当前规模索引的 `CompleteWithinObservedRecords` 只表示已观察记录内部闭合。测试卷通过生成数量与原扫描器逐项对照证明范围完整；个人卷没有这份预先已知的清单，不能直接复用这个成功判据。位图在用但无法解码的记录、未拼接的扩展记录若不能积极证明在范围外，就可能属于所选目录；不能按记录编号、全零或错误类别直接忽略。

建议产品路径在同一快照上增加完整的目录入口清单：按目录句柄批量取得名称、父关系和完整对象身份，以结束游标证明所选范围入口已收集；再由 MFT 提供大小，只有确需补查的对象在同一快照上查询 Native 大小。不信任目录项中可能陈旧的大小。命名空间页、身份、大小、引用、重解析边界或资源预算不满足时，明确回退现有扫描，不能将部分索引当完整结果。接口候选为微软的 [GetFileInformationByHandleEx](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getfileinformationbyhandleex) 与 [FILE_ID_EXTD_DIR_INFO](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_id_extd_dir_info)；快照设备是否支持必须实测，文档存在不等于本项目已支持。

主窗接入还需普通权限主进程与短生命周期助手的绑定通信、扫描 attempt 隔离、来源时间点说明和清理确认。快照结果不复用 live 日志 checkpoint；定位原路径前核对当前身份。已有 `LiveScanSession.Attach` 只允许一次，回退不可混入快路已绑定的 session。这些前置项未通过时不宣称个人磁盘快扫已可用。
