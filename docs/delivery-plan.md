## 建议选择

| 方向 | 优点 | 代价 | 建议 |
| --- | --- | --- | --- |
| Windows x64 自包含部署，附带 .NET 运行时 | 用户不需单独安装 .NET，便携版和安装版共用一份程序内容 | 下载较大；运行时安全更新需要重新发布应用包 | **初版采用** |
| 继续框架依赖部署 | 下载较小，复用用户已安装运行时 | 用户需正确安装 Windows Desktop Runtime；增加启动问题 | 保留为源码开发方式，不增加第二套初版下载选项 |

自包含是文件夹发布，不采用 Native AOT、裁剪或单文件压缩；不在交付任务中改变程序运行架构。微软说明两种部署对运行时的差异，见[发布方式](https://learn.microsoft.com/en-us/dotnet/core/deploying/)。

**安装器建议：Inno Setup，按当前用户安装。** 默认目录为用户本地 Programs 下的 AsukaLens，`PrivilegesRequired=lowest`，固定 AppId；创建开始菜单入口，桌面快捷方式可选。保持当前 AppData 数据位置与软件默认只读行为。`lowest` 的权限语义见 [Inno Setup 官方说明](https://jrsoftware.org/ishelp/topic_setup_privilegesrequired.htm)。

运行时和编译器的许可/通知按实际版本保留。Inno Setup 使用原版编译器，其[许可原文](https://jrsoftware.org/files/is/license.txt)在引入时固定版本与 SHA-256。实施前明确获取的官方编译器及 GitHub CLI 版本，不静默安装未知来源工具。

## 安装、升级与便携行为

1. 便携 ZIP 解压后运行 `AsukaLens.exe`，所有必要 DLL、运行时和许可随附；不要只复制 EXE。这里“便携”指免安装程序目录，**背景、诊断与问题记录仍在当前用户 AppData**，不是随 U 盘迁移的完全便携数据模式。
2. 安装版和便携版保持同一软件与数据契约。安装器写入自己的程序目录与当前用户快捷方式，不添加服务、自启、扫描权限或文件关联。
3. 同 AppId 新版本升级已有安装，保留用户数据；检测程序占用，要求用户关闭或取消，不直接终止进程。升级失败须保留可恢复旧版，实际失败点需测试，不把安装器默认行为当成全部已验证。
4. 默认卸载仅移除安装器拥有的程序和快捷方式，保留背景、诊断、问题记录及外部导出。清空数据沿用应用已有入口；本次不增加卸载递归删除用户目录的选项。
5. 对低于当前安装版本的包给出明确拒绝或提示；不覆盖远程历史资产，不把普通 EXE 改名当安装包。

源码从指定 Git 提交生成，两种压缩包采用同一文件清单并逐文件核对。包含项目、脚本、测试、许可、资源与必要用户说明；排除 `.git`、本机数据、日志、编译缓存、二进制包。迭代归档是否随源码包提供，按明示清单统一处理；完整历史仍可从仓库获取，不能默默使用不同集合。压缩包中的源码应可按 README 在干净目录构建。
