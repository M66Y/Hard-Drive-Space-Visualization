# C55：继续缩放闪黑与卡顿的候选修复

2026-11-21，用户明确要求继续修复，保持布局、背景、字体与动效，完成后先打开正常功能DIB候选、不设默认。C54局部还原残留已验收，不重做该项。

本轮合并定位、定点修改和必要回归。先按固定背景表面类别与透明度拆分重复合成成本；只在有完整键、总预算、像素一致性及失效回退保障下复用结果。同时核实系统尺寸变更与应用内容发布之间的空档，候选中对照在布局稳定后统一补画的方式，保留原生控件、布局和所有内部动效，不录屏或改系统设置。

固定序列同条件前后对比，离散GDI取点与性能分别测；保留旧路径反例与失败证据。必要检查包括两档根/表面/DIB/完整UI、布局/呈现、还原残留和柔光/滚动；涉及的新边界补回归。实际打开C55供用户测试后，再决定是否继续或默认启用，不能由程序取点代替肉眼验收。

系统相关依据：[SetWindowPos](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-setwindowpos)、[WM_NCCALCSIZE](https://learn.microsoft.com/windows/win32/winmsg/wm-nccalcsize)。它们说明窗口尺寸变化、有效像素保留及显式重绘的责任，不直接证明AsukaLens的全部闪黑成因。

## 实施结果与边界

完成精确根缓存的整数位移GDI+发布、候选逻辑尺寸事务中的中间分隔面板擦背景合并；其他原生映射守卫、布局、背景、字体和动效不变。两档27份必要检查通过，候选已打开并检查自然最大化/还原，连续缩放等待用户反馈。

`SWP_NOREDRAW`的尝试没有消除空档，只把黑点挪到PositionEntering，已撤销；不把不同阶段计数变化当修复。最终早期离散黑点仍存在，局部卡顿已改善，不能宣布闪黑根治。详细耗时、验收范围和本机证据入口见[C55记录](../iterations/2026-11-21-55-resize-presentation/README.md)。
