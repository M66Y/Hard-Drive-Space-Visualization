## 核实后的成因

当前 Data 层固定实底，列表的标题、行及空白又各有实色背景；只给外层 Region 裁圆角，不能消除内部的直角白块。InputFrame 和原生控件背景、自定义图片模式下 Label/CheckBox 的实白保护也会再次叠白。四按钮仍由左右弹性分组拉开。NTFS AutoSize CheckBox 与两个输入框的基线、形状和字体来源不同。

旧 620 ms 果冻光圈会向内缩移；上一版 240 ms 顶部短柔光也不符合本次新要求。沿边持续流动需要新的动画生命周期合同，不能沿用旧测试并谎称仍为短时动画。

## 已确认的设计预览

会话内独立预览使用现有背景和图标，示例目录/数值固定，不访问真实目录、快照或设备。它展示：清晰背景；单层半透明暖色承载；内外统一圆角；紧凑四按钮与辅助浅底；沿闭合边缘流动的柔光；两种快扫开关位置。

- 推荐“快扫随扫描设置”：和扫描策略、统计口径同一行，使用同字号的圆角开关及轻量实验标记。
- 对照“快扫随开始操作”：靠近扫描按钮，适合更强调扫描后端选择的呈现。
- 模块先采用约 48% 的暖浅底作为候选，预览允许在 30–70% 间评审；不作为未来全控件统一硬编码值。
- 原预览柔光沿固定圆角路径环流约 2.8 s（最新原生流速按上文提高1.15倍）：一整圈奶油色细底线、约占周长 29% 的暖色软晕，以及约占周长 24% 的细光带。它们共用圆角中心，不能替换为红色硬边或短白峰；不改变面积、命中或标签位置。减弱动效后保留完整静态柔光。

预览中的宽度适配只服务会话展示，不代表 WinForms 最小窗口、不同 DPI、原生控件、字体、对比度或性能验收。

## 原生实施边界

WinForms 原生输入框和 DataGridView 不能仅通过父层透明度获得同样效果。后续需核实统一背景合成/裁切和受控表格绘制，保持 IME、滚动、选择、排序、UIA 及键盘焦点；不能只改 BackColor 或 Framed 开关就宣布完成。

优先减少叠白、加深必要文字和局部保护，避免在深色图片上恢复整片 235/255 遮罩。最终合成可读性需实际测量，预览不是任意背景都可读的保证。

原生持续沿边柔光只维护当前选中和最多一个悬停轮廓、一个有界计时器；只重绘活跃图块。小图块与减弱动效使用静态效果，隐藏、禁用、最小化、取消及 Dispose 时停止和释放；完整轮廓、内部文字与邻居像素、局部重绘和退出恢复需要重新验证。
