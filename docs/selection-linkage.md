# 图表、列表与项目详情

适用于当前第二阶段开发版，尚未打包发布；阶段是否结束等待用户对真实程序的反馈。背景、原布局和1.15倍沿边柔光保留。

- 单击图块选择项目，列表定位到相同对象；已可见的行不会被重复拉到列表顶端。跨页在现有页脚显示定位结果，目标行短暂提亮；开启“减弱动效”后不提亮。
- 单击列表行，图表反向指出同一对象。选择以当前结果树中的对象身份区分，不以同名或同一硬链接身份猜测路径。排序、切换大小口径和连续查询保留仍有效的选择；过滤掉或换为新的结果树时解除失效选择。
- 点击目录内部文件会保留总览，底部显示该文件。当前层列表只有父目录时，父目录仅标“所在目录”，并不作为文件的选中行；点“在列表中查看”才进入文件所在目录并选中它。
- 底部固定两行摘要，长名称省略时为两种大小独立预留位置。点击“详情”核对完整路径、修改时间、两种大小和必要的占用/范围事实；没有悬停气泡或自动说明框。
- 目录的主要动作是“进入目录”，文件是“定位文件”，类型汇总是“查看明细”。合并图块只能查看当前列表，不能定位为一个文件。原有右键定位、复制路径及双击行为继续保留；对快照文件仍进行路径/身份核验。

“实际占用未知”不等于0；目录可显示“已知量＋未知”。硬链接详情展示原生分配量，并说明当前路径是否重复计入范围；实际占用并不等于删除可释放量。类型或合并块只提供当前口径汇总，不为了显示另一口径额外扫描整树。

局限：没有可靠成员映射的旧聚合块不会反向猜测单项；占用未知或没有独立面积的项可能只在列表中可见。跨结果树不自动延续旧选择。完整二维键盘图块导航、UIA子项树、新的导航历史和自定义工作区不在本轮。

实施范围、取舍与验收见[第二阶段方案](ui-stage-two-linkage-plan.md)。软件仍只读分析目录，没有增加删除、移动或运行文件的能力。
