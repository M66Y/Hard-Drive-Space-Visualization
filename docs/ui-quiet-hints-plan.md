# 第一阶段：取消鼠标悬停文字气泡

## 当前范围：C36（2026-11-14）

用户体验C35后明确要求鼠标停留不再产生描述，并确认“开启快扫时说明并确认”。此决定取代下文C35的延迟气泡方案；第一阶段仍未整体接受。

修正版实际主窗展示后，用户于2026-11-14反馈“符合预期，本项通过”，C36本项已验收，不扩大为第一阶段整体接受或第二阶段实施授权。

- 关闭全部应用悬停文字：统一提供器保持停用并取消Popup，列表与诊断表格关闭原生单元格提示，菜单关闭项目提示；移除树图/进度提示及列表独立提示控制器。
- 截断标签也不能产生原生解释框。以无提示的标签绘制保留原始完整Text、可见省略、对齐及必要范围行换行，不因关闭AutoEllipsis导致文字重叠。
- 保留1.15倍沿边柔光、选择联动、完整详情、复制路径、扫描详情和磁盘详情；无障碍描述不随气泡关闭而删除。
- 用户主动从关闭切换为开启NTFS快扫时显示一次说明并确认；取消或确认失败保持关闭，关闭不询问，再次开启需重新确认。同意仅选择扫描方式，不启动扫描，不替代随后每次扫描的管理员授权。
- 说明包括短时只读快照及清理、相邻记录/驻留内容片段、仅解析元信息、本地不上传、链接边界、普通扫描回退和快照期间可能增加的临时磁盘占用。
- 不改变背景裁切、双行列表、紧凑统计卡、图块聚合、C32固定底图/滚动或扫描后端；黑块继续暂缓。

验证使用自有合成控件/目录：无提示策略、确认取消/失败/再次开启、两档DPI下文字与相关模块、完整UI回归及真实主窗观察。自动检查不替代用户自然悬停的体验评价；不进行个人卷/VSS测试，不发布新版本。当前实现与结果见[C36记录](../iterations/2026-11-14-36-no-hover-popups/README.md)。

## C35历史候选：延迟和限制提示（已被上述决定取代）

2026-11-14，承接`9ac1f0b`上的C30–C34未提交工作区。用户指出磁盘活动的单行解释长条挡住视野，界面多处类似；明确选择“统一减少打扰”，并已关闭旧窗口供重建。此范围不等于第一阶段整体接受。

### 当时确认的行为

| 区域 | 调整 |
| --- | --- |
| 侧栏磁盘活动 | 取消整卡动态气泡；现有详情按钮仍有简短提示，完整指标/曲线在详情和可访问描述中保留 |
| 进度区 | 固定短说明，不再把每次扫描阶段和路径更新为悬停长气泡；完整估算解释与当前细节仍在可访问描述，扫描详情入口保留 |
| 空间图 | 延迟显示名称、大小和占比；去掉重复完整路径/操作教程，完整路径仍可在名称列表、选中详情及复制路径中核对 |
| 文件列表 | 名称格保留完整路径提示，有说明的表头也保留；数字格不再重复弹完整路径。停稳约1秒，移动/点击/键盘/滚动/查询变化/失焦等立即取消 |
| 其他必要提示 | 统一约1秒延迟、最多5秒显示、限宽换行，保持原始注册值和必要说明 |

提示内容框最大360×220 DIP，并受工作区约束。显示最多600 UTF-16单位，按完整字素分行；超长或超高以省略号明确表示未显示完，原始值不因绘制而裁改。普通主题采用暖浅底与完整圆角描边，高对比使用系统信息色；字体由每个提供器持有并随其释放。

## 实现与约束

- 复用统一`AppToolTips`提供器；`GridHoverHints`只保存当前一个候选格和一个计时器，不扫描文件、不修改排序/选择/UIA/底图与滚动事务。
- 磁盘活动原本在每秒样本和每秒UI时钟两条路径重设整卡tooltip。已取消整卡注册；不能据此声称原生每次调用都会重弹或重置20秒计时，后者未独立复现。
- 列表显示前重新核对鼠标位置、原格/原文、可见性和真实活动窗体，防止旧路径错配。生产构造使用真实`Form.ActiveForm`；控制器状态测试的显式焦点输入只用于模拟，不当成桌面悬停证明。
- 自定义列表提示同样使用已有`CellToolTipTextNeeded`，只读当前格。独立预览在主窗注册后添加别名转换，不将临时真实根路径带入可见提示。
- 不上传提示内容，不写入路径/名称日志；不改背景、1.15倍柔光、B双行布局、扫描或统计。黑块问题仍暂缓。
