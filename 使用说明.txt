AsukaLens 使用说明

本地诊断
点击主窗“背景设置”旁的“诊断”，可以筛选和查看运行状态、清空运行诊断，勾选记录后预览并保存到本地文件。
最小运行诊断默认开启，可关闭并跨启动保留；最多 8 MiB、14 天，不记录路径、文件名和异常原文，不自动上传。
“问题记录”只保存主动填写的标题、现象和复现步骤，支持编辑删除，最多 100 条 / 1 MiB；不纳入运行诊断导出。
开发记录沿用 Git 与 iterations/。清空运行诊断保留问题记录、背景和已导出文件。详细限制与失败恢复见 docs/diagnostics.md。

版本与分发方式
以当前程序标题、构建标识和随包 build-info.json 为准。标有 LOCAL TEST 的包仅供本机验收，不是正式发布。
源码仓库中的旧“软件”目录和历史 ZIP 不含最新迭代；从源码运行请使用下述开发入口。

浅色界面
使用参考插画作整窗背景，搭配暖白面板和珊瑚色控件。
背景随窗口等比例铺满，边缘可能裁切；图片已内嵌，无需另行放置。
列表的数据行使用实色底，空白区域透出背景。

开始使用
自包含便携包：完整解压后双击 AsukaLens.exe，不需要另外安装 .NET 或 SDK。
安装版：运行安装包，按当前用户安装，从开始菜单启动；升级前请关闭软件，卸载保留用户数据。
便携包和安装版的背景、诊断、问题记录仍保存在当前用户 AppData，不随程序文件夹移动。
源码开发入口：在项目根目录双击 run.cmd（需要 .NET 10 SDK），先构建当前源码，再启动开发预览。
也可在 PowerShell 运行 .\run.ps1；仅构建使用 .\run.ps1 -BuildOnly。
主窗标题显示版本；“诊断 → 开发记录说明”显示构建标识，同版本的不同预览可据此区分。
普通输出是 bin/Release/net10.0-windows/DiskAtlas.exe；直接打开已有 EXE 不会更新源码。
开发版仍在运行或构建失败时，启动入口会明确提示，请处理后重试。历史预览不会被自动关闭。
启动后点击右上角“选择文件夹”，选择电脑上的目录。
也可以把一个文件夹直接拖入程序窗口。

扫描策略与统计口径
顶部“扫描策略”可选择自动、低占用或高速。
自动：固态硬盘最多 8 路；机械硬盘 1 路；网络目录 2 路；未知类型 4 路。
低占用：单路读取，扫描与核验都跨目录累计工作项，每 256 项让步一次。
不足一批不额外等待，也不在每个目录结束时固定等待。
高速：优先并行处理目录；没有排队目录且有空余额度时，对超过 512 个文件的目录补充文件并行。
目录和辅助读取共享最多 8 个执行额度，每批最多 256 项，文件缓冲最多 2,048 项。
自动、低占用与增量/元信息刷新仍在各目录内逐项处理；实际速度受结构、设备和负载影响。
扫描时分别显示读取目录、核验元信息、复用缓存和统计整理阶段。
完成后显示实际任务峰值与策略上限，核验和目录任务分别统计。
点击扫描详情可查看文件读取调用峰值、补充额度峰值、并行批次文件数和缓冲峰值。
任务峰值包含等待，不是 CPU 核数或瞬时磁盘 I/O 数；悬停提示可查看详情。
刷新可能核验并复用旧结果，不宜与首次完整扫描直接比较速度。
扫描开始后暂时锁定策略，下次扫描前可重新选择。
“统计口径”可切换文件大小或实际占用，图块、排序、大小和类型汇总同步切换。
文件大小按每条路径的逻辑长度统计；实际占用读取文件数据的分配大小，
支持压缩和稀疏文件，不包含目录记录、备用数据流等文件系统开销。
同一文件的硬链接只计一次占用，计入扫描范围内路径排序最前的项目；
其他路径标记“共享”，详情仍显示该文件原始占用和系统报告的硬链接数。
文件大小、文件数量仍按路径计数。占用不等于删除该路径后能释放的空间。
无法读取的占用显示“未知”；“已知大小 + 未知”仅代表已核实的部分。

三种视图
空间分布：显示当前文件夹的直接子项，矩形面积与大小成正比。
          文件夹内部的小矩形是下一层预览，双击大矩形进入该文件夹。
大文件：递归查找当前目录下最大的 500 个匹配文件。
文件类型：按扩展名汇总当前目录及所有子目录中的文件，显示文件数。
          双击某个类型，进入该类型的大文件视图，可用“清除类型筛选”恢复。

查看详情
单击矩形或右侧列表，查看名称、大小、占比、完整路径和修改时间。
双击文件夹进入；双击文件可在资源管理器中定位。
“上一级”和“扫描根目录”用于返回。列表列标题可切换排序。
右键列表项目可以复制路径或在资源管理器中定位。
大文件列表的“所在位置”显示相对当前目录的路径，悬停可查看完整路径。
超过 1,000 项时列表分页，底部用“上一页 / 下一页”查看全部项目。
排序作用于全部结果；从图块选中项目时，列表自动转到该项目所在页。
搜索作用于当前视图：空间分布只搜索当前层级名称；大文件搜索所有子目录的文件名；文件类型搜索扩展名或类别。
统计卡一直包含当前目录及全部子目录，不随搜索、类型筛选或分页改变。
列表占比的分母是当前目录未筛选大小；大文件只计算列出的最多 500 项，实际占用只按已知分配量计算。
悬停统计口径、大小卡片或列表说明可查看范围与限制。

扫描与统计
扫描在后台运行，底部显示文件数和已扫描大小，可点击“取消扫描”。
自动策略会按设备类型选择并行数，也可以手动选择低占用或高速。
扫描期间约每 0.5 秒显示当前目录已读取的大小、文件数、图块及列表。
界面会标注“实时预览 / 统计尚未完成”，此时大小和比例还会变化。
可以双击已发现的文件夹进入，也可以返回上一级 / 扫描根目录。
每个目录暂时预览先发现的最多 1,000 项，并在超出时明确提示；
它们不代表整个目录最大的 1,000 项。扫描完成后可查看全部项目。
预览期间暂时停用搜索、大文件与文件类型视图，完成后自动恢复。
预览按文件大小展示；实际占用在完成后统一去重，再恢复所选口径。
自动更新会尽量保留当前目录的选择与滚动位置。
快速扫描可能在第一帧预览前就已完成，此时直接显示完整结果。
取消或失败时保留上一次扫描结果，并明确提示；旧结果若不完整，其提示和未读取详情仍保留。
文件变化后点击“重新扫描”。
重新扫描相同根目录时保留当前子目录、视图、搜索、类型筛选和排序；
如果原来的子目录已不存在，则回到扫描根目录。
搜索、排序和汇总在后台计算，快速切换时会取消旧查询。
无法访问、已删除的项目和链接/联接点会跳过，底部可查看原因。
遇到跳过项、占用未知或目录未读全时，显示“结果不完整”，已读取部分仍可查看。
“查看未读取项”覆盖整次扫描，不受当前目录或筛选影响；两类原因各最多保留 2,000 条。

增量刷新
点击“重新扫描”优先复用已核实的未变部分，只保留本次运行中的缓存。
可读 NTFS 变化日志用于定位改动，并记录扫描开始时的游标，
扫描期间的变化会在下次刷新继续检查；打开的写句柄会保持相关目录待核实。
日志不可用时，会核验全部目录项、文件身份、长度、时间、分配和链接数，
然后复用未变部分。这种模式仍会访问全部元信息，不保证固定加速倍数。
日志断档、目录身份异常或旧结果不完整等情况会完整重扫。
界面区分“日志增量”“元信息核验”“完整扫描”，准备阶段显示正在检查刷新条件。
扫描完成后，点击顶部“点击详情”，或右键“重新扫描”选择“最近完成的扫描详情”。
详情包含实际方式、原因、系统错误码、核验目录及文件数、重扫及复用数，
以及处理日志记录数、准备与读取整理耗时、任务峰值和策略说明。
日志不可用不会伪装为日志增量；不支持的记录、日志断档或身份异常会保守回退。
没有驻留服务、持久化缓存或自动提权；退出后缓存丢弃，重启第一次完整扫描。
Ctrl+F5 或右键“重新扫描”选择“强制完整重新扫描”可绕过复用。

大小使用 1024 进制。符号链接、联接点及其他重解析点不跟随。
隐藏文件和系统文件会尝试读取。空目录、0 字节文件出现在列表中，
由于没有面积，不在矩形图中绘制。矩形图最多单独绘制最大的 240 项，
更小的项目会合并成“其余”图块；右侧列表仍保留当前视图的全部项目。
搜索后的图形按匹配项目重新填满画布，占比仍以当前目录总大小为分母。

快捷键
Ctrl+O 选择文件夹；Ctrl+F 搜索；F5 刷新（按变化证据选择方式）；Ctrl+F5 强制完整扫描；
Alt+↑ 上一级；Esc 清空搜索。

运行环境
自包含发行/验收包面向 Windows 11 x64，内含随包清单标明的 .NET 10 运行时。
源码普通构建需要 .NET 10 Windows Desktop Runtime；开发使用 global.json 指定的 SDK。
源码开发预览已在 Windows 11 x64 验证。干净系统、正式发行的验收状态以 README 和发布说明为准。
其他系统和架构尚未逐一验收。移动程序时完整复制文件夹，保留 DLL、JSON、许可和说明文件。

本程序仅读取文件元信息，不修改或删除扫描内容，不自动联网或上传文件。

扫描反馈与动效
底部右侧百分比是当前阶段目录任务的估算，不是剩余时间或字节进度；新目录出现时可能下降。
核验与读取/复用分别计数，整理阶段沿用读取计数。完整结果结束前最多 99%；取消、失败或结果不完整不显示成功的 100%。
未知总量以往返指示表示，悬停可查看说明。进度标记使用软件头像，已处理部分配合主题强调色。
图块内层高光在悬停和点击时回弹，不改变最终面积或点击位置；采用局部重绘和有限缓存。
空间分布标题右侧“减弱动效”可关闭图块回弹及进度往返动画，此偏好仅在本次运行有效。

背景设置
主窗右上角“背景设置”支持 PNG/JPEG/BMP，限制 24 MiB、4,000 万像素，软件副本最长边 2,048 像素。
可缩放、拖动或输入焦点，自动取色或手动选择强调色，预览包含文字和按钮效果。
点击应用后保存到本机用户数据目录，重启恢复；源图移动或删除不影响已保存副本。
恢复默认先预览，点击应用才保存，取消保留旧设置。恢复默认不删除原图。
读取时可以取消或关闭，保存时请等待完成。失败会按读取、保存或恢复默认分别说明。
